MODULE 09 · ANALYSIS OF COVARIANCE

บทที่ 9: การวิเคราะห์ความแปรปรวนร่วม (ANCOVA)

ผสมผสานเทคนิค ANOVA เข้ากับ Linear Regression เพื่อกำจัดอิทธิพลของตัวแปรร่วม (Covariate) ที่ควบคุมไม่ได้ทางกายภาพ ช่วยเพิ่มความแม่นยำและปรับค่าเฉลี่ยทรีตเมนต์ให้ยุติธรรม

ตัวแบบy_{ij} = \mu + \tau_i + \beta(x_{ij} - \bar{x}_{..}) + \varepsilon_{ij}
บทบาท Covariateปรับลด Error & ปรับค่าเฉลี่ย
ข้อตกลงสำคัญHomogeneity of Slopes
ผลลัพธ์Adjusted Treatment Means
1. การรวม ANOVA + Regression
ใช้ความสัมพันธ์เชิงเส้นระหว่างตัวแปรร่วม X กับตัวแปรตอบสนอง Y เพื่อดูดซับความผันแปรออกจาก Error
2. การปรับค่าเฉลี่ย (Adjusted Means)
ปรับแก้ค่าเฉลี่ยผลผลิตของทรีตเมนต์ให้เสมือนว่าทุกกลุ่มเริ่มต้นจากค่าตัวแปรร่วม X ที่เท่ากันอย่างยุติธรรม
3. ข้อตกลงความชันขนาน
เส้นถดถอยระหว่าง X กับ Y ของแต่ละทรีตเมนต์ต้องมีความชันเท่ากัน (Homogeneity of Slopes: $\beta_1 = \dots = \beta_t$)
COVARIANCE MODEL · ตัวแบบความแปรปรวนร่วม

ตัวแบบเชิงเส้นและข้อกำหนดของ ANCOVA

ตัวแบบเชิงเส้นของการวิเคราะห์ความแปรปรวนร่วมในแผนแบบ CRD:

สมการตัวแบบเชิงเส้น (Linear Model)
$$y_{ij} = \mu + \tau_i + \beta(x_{ij} - \bar{x}_{\cdot\cdot}) + \varepsilon_{ij}$$ โดย $i = 1..t, j = 1..r$
  • $y_{ij}$ = ตัวแปรตอบสนอง (Response Variable)
  • $x_{ij}$ = ตัวแปรร่วม (Covariate) ที่วัดก่อนให้ทรีตเมนต์
  • $\bar{x}_{\cdot\cdot}$ = ค่าเฉลี่ยรวมของตัวแปรร่วม X
  • $\beta$ = สัมประสิทธิ์การถดถอยร่วม (Common Linear Regression Slope)
  • $\varepsilon_{ij} \sim \text{NID}(0, \sigma^2)$ = ความคลาดเคลื่อนสุ่ม
ข้อกำหนดสำคัญของตัวแปรร่วม X
1. X ต้องเป็นอิสระจากทรีตเมนต์: ทรีตเมนต์ต้องไม่มีผลต่อค่า X (ต้องวัดค่า X ก่อนเริ่มการทดลองเสมอ)

2. ความสัมพันธ์เชิงเส้น: X และ Y ต้องมีความสัมพันธ์เชิงเส้นตรงต่อกันอย่างมีนัยสำคัญ

3. ความชันขนาน: ความสัมพันธ์ระหว่าง X กับ Y ต้องมีอัตราการเปลี่ยนแปลง ($\beta$) เท่ากันทุกกลุ่ม
📌
ข้อห้ามร้ายแรง: หากใช้ตัวแปร X ที่วัดหลังจากให้ทรีตเมนต์ไปแล้ว ANCOVA จะดึงอิทธิพลของทรีตเมนต์ทิ้งไปด้วย ทำให้ผลสรุปล้มเหลว
SP & SS PARTITION · ผลรวมกำลังสองและผลคูณไขว้

การแยกผลรวมกำลังสองและผลคูณไขว้ใน ANCOVA

ใน ANCOVA เราต้องสร้างตาราง 3 คอลัมน์ควบคู่กัน: $SS_{xx}, SP_{xy}, SS_{yy}$:

สูตรการคำนวณ Sums of Products & Squares
  • $SS_{xx}$ = ผลรวมกำลังสองของตัวแปรร่วม X
  • $SP_{xy} = \sum \sum (x_{ij} - \bar{x}_{\cdot\cdot})(y_{ij} - \bar{y}_{\cdot\cdot})$ = ผลรวมผลคูณไขว้ระหว่าง X และ Y
  • $SS_{yy}$ = ผลรวมกำลังสองของตัวแปรตอบสนอง Y (เหมือนใน ANOVA ปกติ)
  • ความชันถดถอยร่วมของ Error: $$b_E = \frac{SP_{xy(E)}}{SS_{xx(E)}}$$
ผลรวมกำลังสองปรับแก้ (Adjusted SS)
ผลรวมกำลังสองของ Error ที่ปรับแก้แล้ว:
$$SS_{E(adj)} = SS_{yy(E)} - \frac{(SP_{xy(E)})^2}{SS_{xx(E)}}, \quad df = N - t - 1$$
ผลรวมกำลังสองปรับแก้ของทรีตเมนต์:
$$SS_{\text{Tr}(adj)} = SS_{\text{Total}(adj)} - SS_{E(adj)}, \quad df = t - 1$$
💡
การลดทอน: พจน์ $\frac{(SP_{xy(E)})^2}{SS_{xx(E)}}$ คือปริมาณความผันแปรที่ตัวแปรร่วม X ช่วยดูดซับออกจาก Error

HISTORICAL VIGNETTE · ประวัติศาสตร์สถิติโลก

เรื่องเล่าประวัติศาสตร์: การขุนสุกรด้วยน้ำหนักแรกเกิดที่ไม่เท่ากัน (Swine Nutrition)

"ลูกหมูที่เกิดมาตัวใหญ่กว่า ย่อมโตเร็วกว่า... เราจะรู้ได้อย่างไรว่าอาหารสูตรไหนดีจริง หรือแค่ได้หมูตัวอ้วนแต่แรก?"

ในการทดลองเปรียบเทียบอาหารสัตว์ 4 สูตร สุกรแต่ละตัวมีน้ำหนักเริ่มต้น (Covariate X) ต่างกันตั้งแต่เกิด หากวัดเฉพาะน้ำหนักสุดท้าย (Y) อาหารที่สุ่มได้ลูกหมูตัวโตแต่แรกจะชนะเสมอ ANCOVA รวมเทคนิค ANOVA เข้ากับ Linear Regression เพื่อปรับระดับน้ำหนักเริ่มต้นให้เท่ากันอย่างยุติธรรม

บทเรียนสำคัญสู่ทฤษฎี
การควบคุมทางสถิติ (Statistical Control ด้วย ANCOVA) สามารถทำหน้าที่ทดแทนการควบคุมทางกายภาพ (Local Control) ได้อย่างมีประสิทธิภาพเมื่อไม่สามารถจัดบล็อกได้
REAL CASE STUDY · การทดลองจริงภาคสนาม

กรณีศึกษาจริง: การประเมินคะแนนสอบอบรมโดยใช้คะแนน Pre-test เป็น Covariate

บริบทและการประยุกต์ใช้ในไทย
การทดสอบวิธีสอน 3 วิธีในการอบรมครู นิสิตหรือผู้เข้ารับการอบรมมีความรู้พื้นฐานไม่เท่ากัน การนำคะแนนทดสอบก่อนเรียน (Pre-test) มาเป็นตัวแปรร่วม X ช่วยดูดซับความต่างของความรู้เดิมออกจาก Error ทำให้ตรวจวัดประสิทธิผลที่แท้จริงของวิธีสอนได้อย่างเที่ยงตรง
คำแนะนำสำหรับวิทยานิพนธ์

ตรวจข้อกำหนด Homogeneity of Slopes เสมอ หากพบว่าวิธีสอนหนึ่งเหมาะกับคนเก่ง แต่อีกวิธีเหมาะกับคนไม่เก่ง (ความชันไม่เท่ากัน) จะใช้ ANCOVA ไม่ได้ ต้องใช้ Moderated Regression แทน

WORKED EXAMPLE · ตัวอย่างการคำนวณจริง

ตัวอย่างการคำนวณ ANCOVA ในการทดลองขุนสุกร

เปรียบเทียบสูตรอาหารสุกร $t=3$ สูตร ($r=4$ ตัวต่อสูตร, $N=12$) โดย $X$ = น.น. แรกเกิด, $Y$ = น.น. สุดท้าย:

1. การคำนวณความชันร่วมและ Adjusted Error
  • $SS_{xx(E)} = 120.0, \quad SP_{xy(E)} = 144.0, \quad SS_{yy(E)} = 220.0$
  • ความชันถดถอยร่วม: $b_E = \frac{144.0}{120.0} = 1.20$ กก.สุดท้าย/กก.แรกเกิด
  • $SS_{E(adj)} = 220.0 - \frac{144.0^2}{120.0} = 220.0 - 172.8 = 47.20$
  • $df_{E(adj)} = 12 - 3 - 1 = 8 \implies MS_{E(adj)} = 47.20 / 8 = 5.90$
  • สังเกต: $MS_E$ ดั้งเดิมคือ $220 / 9 = 24.44$ ANCOVA ลด Error ลงเหลือเพียง 5.90!
2. การปรับค่าเฉลี่ยทรีตเมนต์ (Adjusted Means)
  • ค่าเฉลี่ยรวม: $\bar{x}_{\cdot\cdot} = 5.0$ กก., $b_E = 1.20$
  • สูตร 1 (หมูตัวเล็ก): $\bar{x}_1 = 3.0, \bar{y}_1 = 45.0 \implies \bar{y}_{1(adj)} = 45.0 - 1.2(3.0 - 5.0) = 47.4$ กก.
  • สูตร 2 (หมูปกติ): $\bar{x}_2 = 5.0, \bar{y}_2 = 52.0 \implies \bar{y}_{2(adj)} = 52.0 - 1.2(5.0 - 5.0) = 52.0$ กก.
  • สูตร 3 (หมูตัวโต): $\bar{x}_3 = 7.0, \bar{y}_3 = 55.0 \implies \bar{y}_{3(adj)} = 55.0 - 1.2(7.0 - 5.0) = 52.6$ กก.
  • สมมติ $SS_{\text{Tr}(adj)} = 68.4 \implies F = \frac{68.4/2}{5.90} = 5.80 > F_{0.05, 2, 8} = 4.46$ (Sig!)
📊
ข้อค้นพบ: น้ำหนักดิบสูตร 3 สูงสุด (55.0) เพราะได้หมูตัวใหญ่แต่แรก แต่เมื่อปรับแก้ด้วย ANCOVA สูตร 2 และ 3 ให้ผลใกล้เคียงกัน
FORENSIC AUDIT · คดีสืบสวนข้อผิดพลาด

แฟ้มคดีอาชญากรรมทางสถิติ: 3 กับดักยอดฮิต

ตรวจสอบงานวิจัยของท่านด้วย Checklist วินิจฉัยนี้ก่อนลงมือปฏิบัติจริง:

CASE 01
ใช้ Covariate X ที่ได้รับอิทธิพลจากทรีตเมนต์: เลือกตัวแปร X ที่เกิดขึ้นหลังจากการให้ทรีตเมนต์ เช่น วัดปริมาณการกินอาหารหลังให้ยา ละเมิดข้อตกลงว่า X ต้องเป็นอิสระจากทรีตเมนต์
CASE 02
ไม่ตรวจสอบความชันร่วม (Homogeneity of Slopes): ทำ ANCOVA โดยไม่ทดสอบว่าเส้นถดถอยของแต่ละทรีตเมนต์ขนานกันหรือไม่ หากความชันไม่เท่ากัน (β1 ≠ β2) จะไม่สามารถปรับค่าเฉลี่ยได้
CASE 03
รายงาน Unadjusted Means แทน Adjusted Means: นำค่าเฉลี่ยดิบของ Y ไปรายงานและทำ Post-hoc แทนที่จะใช้ค่าเฉลี่ยที่ปรับแก้แล้ว ȳ_i(adj) ทำให้ข้อสรุปผิดพลาด
🔍
หลักการเตือนใจ: ทดสอบสมมติฐาน $H_0: \beta_1 = \dots = \beta_t$ ก่อนทำ ANCOVA เสมอ หากเส้นถดถอยไม่ขนานกัน การปรับค่าเฉลี่ยด้วยความชันเดี่ยวจะผิดทิศทาง
