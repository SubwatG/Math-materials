บทที่ 2: แผนการทดลองแบบสุ่มสมบูรณ์ (CRD)

แผนแบบการทดลองพื้นฐานที่ง่ายและตรงไปตรงมาที่สุด เหมาะสำหรับหน่วยทดลองที่มีความสม่ำเสมอเป็นเนื้อเดียวกัน (Homogeneous Units) อย่างแท้จริง

ตัวแบบy_{ij} = \mu + \tau_i + \varepsilon_{ij}
ข้อสมมติหน่วยHomogeneous Units
การแยก SSSS_{\text{Total}} = SS_{\text{Tr}} + SS_E
องศาอิสระ ErrorN - t
1. ลักษณะสำคัญ
ทรีตเมนต์ทุกทรีตเมนต์ถูกจัดสรรลงสู่หน่วยทดลองแบบสุ่มอิสระ 100% โดยไม่มีข้อจำกัดของการจัดบล็อก
2. จุดเด่นสูงสุด
ให้องศาอิสระของความคลาดเคลื่อน ($df_E = N - t$) สูงที่สุด และคำนวณง่ายแม้จำนวนซ้ำในแต่ละกลุ่มจะไม่เท่ากัน ($r_i \neq r_j$)
3. ข้อจำกัดสำคัญ
หากหน่วยทดลองไม่สม่ำเสมอ ความผันแปรของดินหรือสิ่งแวดล้อมจะไหลไปรวมอยู่ใน $SS_E$ ทำให้ $MS_E$ บวมจนตรวจไม่พบความต่าง
LINEAR MODEL · ตัวแบบทางคณิตศาสตร์

ตัวแบบเชิงเส้นและข้อกำหนดของ CRD

ตัวแบบเชิงเส้นของ CRD สำหรับแผนแบบปัจจัยเดี่ยว (Single-Factor Experiment):

สมการตัวแบบเชิงเส้น (Linear Model)
$$y_{ij} = \mu + \tau_i + \varepsilon_{ij}$$ โดย $i = 1, \dots, t$ และ $j = 1, \dots, r_i$
  • $y_{ij}$ = ค่าสังเกตของหน่วยทดลองที่ได้รับทรีตเมนต์ $i$ ซ้ำที่ $j$
  • $\mu$ = ค่าเฉลี่ยรวมแท้จริง (Overall True Mean)
  • $\tau_i$ = อิทธิพลของทรีตเมนต์ที่ $i$ โดย $\sum_{i=1}^t \tau_i = 0$ (Fixed Effect)
  • $\varepsilon_{ij}$ = ความคลาดเคลื่อนสุ่ม โดย $\varepsilon_{ij} \sim \text{NID}(0, \sigma^2)$
Fixed Effect vs Random Effect
Fixed Effect: ผู้วิจัยสนใจเฉพาะ $t$ ทรีตเมนต์ที่เลือกมาเท่านั้น สมมติฐานคือ $H_0: \tau_1 = \dots = \tau_t = 0$

Random Effect: ทรีตเมนต์สุ่มมาจากประชากรทรีตเมนต์ขนาดใหญ่ โดย $\tau_i \sim \text{NID}(0, \sigma_\tau^2)$ สมมติฐานคือ $H_0: \sigma_\tau^2 = 0$
📌
ข้อตกลงสำคัญ: ความคลาดเคลื่อน $\varepsilon_{ij}$ ต้องเป็นอิสระต่อกัน มีการแจกแจงแบบปกติ และมีความแปรปรวนคงที่ $\sigma^2$ ทุกกลุ่ม
SS DECOMPOSITION · การแยกผลรวมกำลังสอง

การแยกผลรวมกำลังสองและองศาอิสระใน CRD

ใน CRD ความแปรปรวนรวมทั้งหมด ($SS_{\text{Total}}$) ถูกผ่าออกเป็น 2 ก้อนอิสระต่อกัน:

สูตรการแยกผลรวมกำลังสอง (Sums of Squares)
$$SS_{\text{Total}} = SS_{\text{Tr}} + SS_E$$
$$CF = \frac{Y_{\cdot\cdot}^2}{N}, \quad SS_{\text{Total}} = \sum_{i=1}^t \sum_{j=1}^{r_i} y_{ij}^2 - CF$$
$$SS_{\text{Tr}} = \sum_{i=1}^t \frac{Y_{i\cdot}^2}{r_i} - CF, \quad SS_E = SS_{\text{Total}} - SS_{\text{Tr}}$$
การกระจายองศาความเป็นอิสระ (Degrees of Freedom)
  • $df_{\text{Total}} = N - 1$ (จำนวนข้อมูลทั้งหมดลบ 1)
  • $df_{\text{Tr}} = t - 1$ (จำนวนทรีตเมนต์ลบ 1)
  • $df_E = N - t = t(r - 1)$ (องศาอิสระของ Error)
  • สมบัติบวกสะสม: $df_{\text{Total}} = df_{\text{Tr}} + df_E$
💡
ความหมายทางเรขาคณิต: $SS_{\text{Tr}}$ วัดระยะห่างระหว่างค่าเฉลี่ยแต่ละกลุ่มกับค่าเฉลี่ยรวม ส่วน $SS_E$ วัดความผันแปรภายในกลุ่มเดียวกัน (Within-group)

HISTORICAL VIGNETTE · ประวัติศาสตร์สถิติโลก

เรื่องเล่าประวัติศาสตร์: William S. Gosset & โรงเบียร์ Guinness (1900s)

"การทดลองในโรงต้มเบียร์ เราไม่สามารถใช้ตัวอย่างขนาดใหญ่ระดับพันตัวอย่างได้... เราต้องเค้นความจริงจากตัวอย่างขนาดเล็ก!"

วิลเลียม ซีลี กอสเซต (นามปากกา 'Student') นักเคมีประจำโรงเบียร์กินเนสส์ในดับลิน ต้องทดสอบสายพันธุ์ข้าวบาร์เลย์ในถังหมักที่มีสภาพแวดล้อมสม่ำเสมอ เขาค้นพบการแจกแจง t (Student's t-distribution) และวางรากฐานการทดสอบเปรียบเทียบในหน่วยทดลองที่เป็นเนื้อเดียวกัน (Homogeneous)

บทเรียนสำคัญสู่ทฤษฎี
เมื่อสภาพแวดล้อมควบคุมได้สม่ำเสมอสมบูรณ์ การใช้แผนแบบ CRD ร่วมกับการทดสอบทางสถิติที่แม่นยำ จะให้ประสิทธิภาพสูงสุดโดยไม่ต้องสิ้นเปลืององศาอิสระให้กับการจัดบล็อก
REAL CASE STUDY · การทดลองจริงภาคสนาม

กรณีศึกษาจริง: การทดลองในเรือนกระจกควบคุมสภาพแวดล้อม (Greenhouse Trials)

บริบทและการประยุกต์ใช้ในไทย
การทดสอบพันธุ์ถั่วเหลืองในกระถางปลูกที่วางบนโต๊ะหมุนในเรือนกระจกปรับอุณหภูมิ ณ มก. กำแพงแสน หน่วยทดลองทุกหน่วยได้รับแสง ดินผสม และน้ำอย่างเท่าเทียมกัน CRD จึงเป็นแผนแบบที่ให้ความคลาดเคลื่อนต่ำสุดและให้องศาอิสระของ Error สูงที่สุด (df_E = N - t)
คำแนะนำสำหรับวิทยานิพนธ์

หากจะใช้ CRD ต้องมั่นใจว่าโต๊ะปลูกหรือตู้ทดลองไม่มี Gradient อุณหภูมิหรือแสง หากมีทิศทางแสงแดดส่องเข้าด้านเดียว ห้ามใช้ CRD เด็ดขาด ต้องเปลี่ยนเป็น RCBD

WORKED EXAMPLE · ตัวอย่างการคำนวณจริง

ตัวอย่างการคำนวณตาราง ANOVA ของ CRD ทีละขั้นตอน

สมมติข้อมูลการทดสอบพันธุ์ข้าวบาร์เลย์ 4 พันธุ์ ($t=4$) ทำซ้ำพันธุ์ละ 4 ซ้ำ ($r=4, N=16$) มีข้อมูลดังนี้:

1. คำนวณ Correction Factor และ SS รวม
  • ผลรวมแต่ละพันธุ์: $Y_{1\cdot}=180, Y_{2\cdot}=220, Y_{3\cdot}=190, Y_{4\cdot}=210$
  • ผลรวมรวม: $Y_{\cdot\cdot} = 180 + 220 + 190 + 210 = 800.0$
  • ผลรวมกำลังสองข้อมูลดิบ: $\sum y_{ij}^2 = 40,320.0$
  • $CF = \frac{800^2}{16} = 40,000.0$
  • $SS_{\text{Total}} = 40,320.0 - 40,000.0 = 320.0$
2. คำนวณ SS_Tr, SS_E และสถิติทดสอบ F
  • $SS_{\text{Tr}} = \frac{180^2 + 220^2 + 190^2 + 210^2}{4} - 40,000.0 = 260.0$
  • $SS_E = 320.0 - 260.0 = 60.0$
  • $MS_{\text{Tr}} = 260.0 / 3 = 86.67, \quad MS_E = 60.0 / 12 = 5.00$
  • $F_{\text{calc}} = \frac{86.67}{5.00} = 17.33$
  • $F_{0.05, 3, 12} = 3.49 \implies F_{\text{calc}} > 3.49$ (Sig!)
📊
สรุปผลการทดลอง: ปฏิเสธ $H_0$ ค่าเฉลี่ยผลผลิตของข้าวบาร์เลย์อย่างน้อย 1 คู่แตกต่างกันอย่างมีนัยสำคัญทางสถิติที่ระดับ $\alpha = 0.05$
FORENSIC AUDIT · คดีสืบสวนข้อผิดพลาด

แฟ้มคดีอาชญากรรมทางสถิติ: 3 กับดักยอดฮิต

ตรวจสอบงานวิจัยของท่านด้วย Checklist วินิจฉัยนี้ก่อนลงมือปฏิบัติจริง:

CASE 01
นำ CRD ไปใช้ในแปลงดินลาดชัน: นำ CRD ไปจัดในแปลงเปิดที่มีความลาดชันของดิน ทำให้ความผันแปรของดินไหลไปบวมอยู่ใน SS_E จนค่า F ต่ำเตี้ย ไม่พบความต่าง
CASE 02
ลืมหัก Correction Factor (CF): คำนวณ SS_Tr และ SS_Total โดยลืมหักพจน์ CF = Y..² / N ทำให้ผลรวมกำลังสองมีค่ามหาศาลและผิดพลาดทางคณิตศาสตร์
CASE 03
นับต้นไม้ในกระถางเดียวกันเป็นหน่วยทดลองอิสระ: รดปุ๋ยลงในกระถาง 1 ใบที่มีต้นไม้ 5 ต้น แล้วรายงานว่ามี 5 ซ้ำ (Pseudoreplication) แท้จริงคือ r = 1 กระถางเท่านั้น
🔍
หลักการเตือนใจ: ใน CRD หน่วยทดลองต้องเป็นอิสระต่อกันและมีสภาพแวดล้อมสม่ำเสมอ หากมีปัจจัยรบกวนภายนอก ต้องจัดบล็อก (RCBD) ทันที
ROADMAP · สรุปและก้าวถัดไป

สรุปหัวใจสำคัญของบทที่ 2

สิ่งสำคัญที่ได้เรียนรู้
  • CRD เป็นแผนแบบพื้นฐานสำหรับหน่วยทดลองที่เป็นเนื้อเดียวกัน (Homogeneous)
  • การแยกผลรวมกำลังสอง: $SS_{\text{Total}} = SS_{\text{Tr}} + SS_E$ โดยมี $df_E = N - t$
  • เมื่อ $F$-test มีนัยสำคัญ ต้องทำการเปรียบเทียบเชิงพหุคูณ (Post-hoc) ต่อไป
ความเชื่อมโยงสู่บทต่อไป
