MODULE 05 · LATIN SQUARE DESIGN

บทที่ 5: แผนการทดลองแบบลาตินสแควร์ (Latin Square)

ควบคุมความผันแปรของสภาพแวดล้อมได้ถึงสองทิศทางพร้อมกัน (แถวและคอลัมน์) โดยใช้จำนวนหน่วยทดลองเพียง t² หน่วยได้อย่างมีประสิทธิภาพสูงสุด

ตัวแบบy_{ijk} = \mu + \tau_i + \rho_j + \gamma_k + \varepsilon_{ijk}
การควบคุม2-Way Blocking (Row & Col)
เงื่อนไขr = c = t (Square Matrix)
df Error(t - 1)(t - 2)
1. การบล็อกสองทาง
บล็อกทิศทางที่หนึ่งตามแถว (Row) และบล็อกทิศทางที่สองตามคอลัมน์ (Column) ขจัดอิทธิพลกวนแฝงได้พร้อมกัน 2 แหล่ง
2. กฎการวางทรีตเมนต์
ทรีตเมนต์แต่ละตัวจะต้องปรากฏในแต่ละแถวและแต่ละคอลัมน์เพียงครั้งเดียวพอดี (คล้ายตารางซูโดกุ)
3. ข้อจำกัดสำคัญ
จำนวนแถว คอลัมน์ และทรีตเมนต์ต้องเท่ากันเสมอ หากทรีตเมนต์น้อย ($t \le 4$) องศาอิสระของ Error จะต่ำมาก
LINEAR MODEL · ตัวแบบทางสถิติ

ตัวแบบเชิงเส้นและข้อกำหนดของ Latin Square

ตัวแบบเชิงเส้นของการจัดบล็อกสองทิศทางตั้งฉาก:

สมการตัวแบบเชิงเส้น (Linear Model)
$$y_{ijk} = \mu + \tau_i + \rho_j + \gamma_k + \varepsilon_{ijk}$$ โดย $i, j, k = 1, \dots, t$
  • $y_{ijk}$ = ค่าสังเกตของทรีตเมนต์ $i$ ในแถว $j$ และคอลัมน์ $k$
  • $\mu$ = ค่าเฉลี่ยรวมแท้จริง
  • $\tau_i$ = อิทธิพลทรีตเมนต์ที่ $i$ โดย $\sum \tau_i = 0$
  • $\rho_j$ = อิทธิพลแถวที่ $j$ โดย $\sum \rho_j = 0$
  • $\gamma_k$ = อิทธิพลคอลัมน์ที่ $k$ โดย $\sum \gamma_k = 0$
  • $\varepsilon_{ijk} \sim \text{NID}(0, \sigma^2)$ = ความคลาดเคลื่อนสุ่ม
สมมติฐาน Additivity และข้อจำกัดขนาด
1. ไม่มี Interaction: สมมติว่าไม่มีปฏิสัมพันธ์ใดๆ ระหว่าง Treatments, Rows และ Columns

2. จัตุรัสสมบูรณ์: จำนวนระดับของทั้ง 3 ปัจจัยต้องเท่ากันคือ $t$

3. ข้อจำกัด: หาก $t=3$ จะได้ $df_E = (3-1)(3-2) = 2$ ซึ่งต่ำเกินไปสำหรับการทดสอบที่แม่นยำ
📌
ข้อสังเกต: หากสงสัยว่าทรีตเมนต์จะมีปฏิกิริยาร่วมกับแถวหรือคอลัมน์ ห้ามใช้ Latin Square เด็ดขาด
SS DECOMPOSITION · การแยกผลรวมกำลังสอง

การแยกผลรวมกำลังสอง 4 ส่วนใน Latin Square

ใน Latin Square ความแปรปรวนรวม ($SS_{\text{Total}}$) ถูกผ่าออกเป็น 4 ก้อนอิสระ:

สูตรการคำนวณ Sums of Squares
$$SS_{\text{Total}} = SS_{\text{Tr}} + SS_{\text{Row}} + SS_{\text{Col}} + SS_E$$
$$CF = \frac{Y_{\cdot\cdot\cdot}^2}{t^2}, \quad SS_{\text{Total}} = \sum \sum \sum y_{ijk}^2 - CF$$
$$SS_{\text{Tr}} = \frac{\sum Y_{i\cdot\cdot}^2}{t} - CF, \quad SS_{\text{Row}} = \frac{\sum Y_{\cdot j\cdot}^2}{t} - CF$$
$$SS_{\text{Col}} = \frac{\sum Y_{\cdot\cdot k}^2}{t} - CF$$
การกระจายองศาความเป็นอิสระ (df)
  • $df_{\text{Total}} = t^2 - 1$
  • $df_{\text{Tr}} = t - 1$
  • $df_{\text{Row}} = t - 1$
  • $df_{\text{Col}} = t - 1$
  • $df_E = (t - 1)(t - 2)$
  • สมบัติบวก: $df_{\text{Total}} = 3(t - 1) + (t - 1)(t - 2)$
💡
ความประหยัด: ใช้เพียง $t^2$ หน่วยทดลอง แทนที่จะต้องใช้ $t^3$ หน่วยเหมือนใน Factorial สามปัจจัยเต็มรูป
ANOVA TABLE · ตารางวิเคราะห์ความแปรปรวน

ตาราง ANOVA ของ Latin Square และประสิทธิภาพสัมพัทธ์

โครงสร้างตารางวิเคราะห์ความแปรปรวนสำหรับ Latin Square Design:

HISTORICAL VIGNETTE · ประวัติศาสตร์สถิติโลก

เรื่องเล่าประวัติศาสตร์: ปัญหา 36 นายทหารของออยเลอร์ สู่ตารางโคนม

"จัดนายทหาร 36 นายจาก 6 กองพัน 6 ยศ ลงในแถว 6x6 โดยไม่ให้ยศหรือกองพันซ้ำกันในแถวและคอลัมน์!"

เลออนฮาร์ด ออยเลอร์ (Leonhard Euler, 1779) ตั้งปัญหาคณิตศาสตร์บริสุทธิ์เรื่องจัตุรัสละติน ซึ่งต่อมาฟิชเชอร์นำมาประยุกต์เป็นแผนแบบการทดลองที่ควบคุมความผันแปรภายนอกได้ถึง 2 มิติพร้อมกัน โดยใช้จำนวนหน่วยทดลองเพียง t² หน่วย แทนที่จะต้องใช้ t³ หน่วยแบบแฟกทอเรียลเต็มรูป

บทเรียนสำคัญสู่ทฤษฎี
คณิตศาสตร์เชิงการจัด (Combinatorics) กลายมาเป็นเครื่องมืออันทรงพลังในการประหยัดทรัพยากรการทดลองภาคสนาม
REAL CASE STUDY · การทดลองจริงภาคสนาม

กรณีศึกษาจริง: การทดสอบอาหารโคนม 4 สูตร (Dairy Cow Nutrition)

บริบทและการประยุกต์ใช้ในไทย
โคนม 4 ตัว (Row Blocking: ควบคุมพันธุกรรมและขนาดตัว) ทดสอบตลอด 4 ช่วงเวลาการให้นม (Column Blocking: ควบคุมระยะการให้นมตามอายุ) สลับรับอาหารสูตร A, B, C, D แผนแบบลาตินสแควร์ทำให้ตัดอิทธิพลความต่างระหว่างตัววัวและช่วงเวลาออกจากการทดสอบสูตรอาหารได้อย่างหมดจด
คำแนะนำสำหรับวิทยานิพนธ์

ระวังเรื่อง Residual Carryover Effect หากอาหารในรอบก่อนหน้ายังมีผลตกค้างถึงรอบถัดไป ต้องเว้นระยะล้างท้อง (Washout Period) ระหว่างช่วงเวลาเสมอ

INTERACTIVE LAB · แบบจำลองสถานการณ์จริง

ห้องทดลองจำลองเชิงโต้ตอบประจำบทเรียน

สุ่มผังแปลง Latin Square 4x4
กฎเหล็ก: ทรีตเมนต์ A, B, C, D ต้องปรากฏในแต่ละแถวและแต่ละคอลัมน์เพียงครั้งเดียวพอดี ควบคุม 2 ทิศทางตั้งฉาก
✅ ผังลาตินสแควร์ถูกต้อง: ควบคุมความผันแปรของแถวและคอลัมน์ได้ 100%
WORKED EXAMPLE · ตัวอย่างการคำนวณจริง

ตัวอย่างการคำนวณ Latin Square ขนาด 4x4

สมมติการทดสอบอาหารโคนม 4 สูตร ($t=4, N=16$) ได้ผลรวมดังนี้:

1. การคำนวณตาราง ANOVA ของ Latin Square
  • $CF = 40,000.0, \quad SS_{\text{Total}} = 410.0$
  • $SS_{\text{Tr}} = 240.0, \quad SS_{\text{Row}} = 80.0, \quad SS_{\text{Col}} = 60.0$
  • $SS_E = 410.0 - 240.0 - 80.0 - 60.0 = 30.0$
  • $df_E = (4 - 1)(4 - 2) = 6, \quad MS_E = 30.0 / 6 = 5.00$
  • $MS_{\text{Tr}} = 240.0 / 3 = 80.0$
  • $F_{\text{calc}} = 80.0 / 5.00 = 16.00 > F_{0.05, 3, 6} = 4.76$ (Sig!)
2. การคำนวณ RE และการทำซ้ำจัตุรัส
  • $MS_{\text{Row}} = 80.0 / 3 = 26.67, \quad MS_{\text{Col}} = 60.0 / 3 = 20.00$
  • $RE = \frac{26.67 + 20.00 + 3(5.00)}{5(5.00)} = \frac{61.67}{25.0} = 246.7\%$
  • การจัด Latin Square ให้ประสิทธิภาพสูงกว่า CRD ถึง 146.7%!
  • เทคนิค Repetition: หาก $t=3$ หรือ $4$ ให้ทำซ้ำจัตุรัสละติน $m$ จัตุรัส (Replication of Latin Squares) เพื่อเพิ่ม $df_E$
📊
สรุป: แผนแบบลาตินสแควร์ช่วยขจัดความแปรปรวนจากทั้งตัวสัตว์และช่วงเวลาได้อย่างคุ้มค่ามหาศาล
FORENSIC AUDIT · คดีสืบสวนข้อผิดพลาด

แฟ้มคดีอาชญากรรมทางสถิติ: 3 กับดักยอดฮิต

ตรวจสอบงานวิจัยของท่านด้วย Checklist วินิจฉัยนี้ก่อนลงมือปฏิบัติจริง:

CASE 01
ทรีตเมนต์มี Interaction กับแถวหรือคอลัมน์: ใช้ Latin Square ในสถานการณ์ที่สูตรอาหารให้ผลต่างกันตามระยะการให้นม ละเมิดข้อสมมติ Additivity อย่างรุนแรง
CASE 02
ใช้ขนาดจัตุรัสเล็กเกินไป (t = 3): ใช้ลาตินสแควร์ขนาด 3x3 ส่งผลให้ df_E = (3-1)(3-2) = 2 ทำให้การทดสอบ F แทบไม่มีอำนาจทดสอบ (Power ต่ำมาก) ควรใช้ Repetition of Latin Squares
CASE 03
จัดผังแปลงโดยไม่สุ่มแถวและคอลัมน์: หยิบจัตุรัสมาตรฐาน (Standard Square) มาใช้ตรงๆ โดยไม่สุ่มสลับแถวและคอลัมน์ก่อนลงแปลงจริง
🔍
หลักการเตือนใจ: ขนาดจัตุรัสที่เหมาะสมที่สุดคือ $5 \times 5$ ถึง $8 \times 8$ หากเล็กกว่านี้ $df_E$ จะน้อย หากใหญ่กว่านี้จะหาหน่วยทดลองที่เท่ากันทั้ง 2 ทิศทางได้ยาก

สิ่งสำคัญที่ได้เรียนรู้
  • Latin Square ควบคุมความผันแปร 2 ทิศทางตั้งฉาก (Row และ Column)
  • การแยกผลรวมกำลังสอง 4 ส่วน: $SS_{\text{Total}} = SS_{\text{Tr}} + SS_{\text{Row}} + SS_{\text{Col}} + SS_E$
  • ต้องระวังเรื่องสมมติฐาน Additivity และข้อจำกัด $df_E$ เมื่อ $t$ มีขนาดเล็ก
