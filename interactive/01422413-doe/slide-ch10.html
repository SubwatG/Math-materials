MODULE 10 · SPLIT-PLOT DESIGN

บทที่ 10: แผนการทดลองแบบสปลิท-พลอท (Split-Plot)

เมื่อปัจจัยหนึ่งต้องใช้พื้นที่ขนาดใหญ่และเปลี่ยนระดับได้ยาก (Main Plot) แต่อีกปัจจัยเปลี่ยนได้ง่ายในแปลงย่อย (Subplot) ก่อให้เกิดโครงสร้างความคลาดเคลื่อนสองระดับ (E_a และ E_b) ในตารางเดียว

โครงสร้าง Error2 ระดับ: Error_a และ Error_b
Main Plotปัจจัยที่เปลี่ยนยาก (คลอง/รถไถ)
Subplotปัจจัยที่เปลี่ยนง่าย (ปุ๋ย/พันธุ์)
การสุ่มTwo-Stage Randomization
1. การสุ่มสองจังหวะ
จังหวะที่ 1 สุ่มปัจจัย A ลงในแปลงใหญ่ (Main Plot) จังหวะที่ 2 สุ่มปัจจัย B ลงในแปลงย่อย (Subplot) ภายในแปลงใหญ่แต่ละแปลง
2. ความคลาดเคลื่อน 2 ตัว
Error_a ใช้ทดสอบปัจจัยแปลงใหญ่ A ส่วน Error_b ใช้ทดสอบปัจจัยแปลงย่อย B และอิทธิพลร่วม AB
3. ความแม่นยำไม่เท่ากัน
ปัจจัยแปลงย่อย B และ Interaction AB จะมีความแม่นยำสูงกว่าปัจจัยแปลงใหญ่ A เสมอ ($MS_{E_b} < MS_{E_a}$)
TWO-STAGE MODEL · ตัวแบบสองจังหวะ

ตัวแบบเชิงเส้นของการทดลอง Split-Plot

ตัวแบบเชิงเส้นของ Split-Plot Design เมื่อจัดแปลงใหญ่ในแผนแบบ RCBD:

สมการตัวแบบเชิงเส้น (Linear Model)
$$y_{ijk} = \mu + R_j + A_i + E_{a(ij)} + B_k + (AB)_{ik} + E_{b(ijk)}$$ โดย $i=1..a, j=1..r, k=1..b$
  • $R_j$ = อิทธิพลของบล็อก ($df = r - 1$)
  • $A_i$ = อิทธิพลของปัจจัยแปลงใหญ่ (Main Plot Factor A)
  • $E_{a(ij)} \sim \text{NID}(0, \sigma_a^2)$ = ความคลาดเคลื่อนแปลงใหญ่ (Whole-Plot Error)
  • $B_k$ = อิทธิพลของปัจจัยแปลงย่อย (Subplot Factor B)
  • $(AB)_{ik}$ = อิทธิพลร่วมระหว่าง A และ B
  • $E_{b(ijk)} \sim \text{NID}(0, \sigma_b^2)$ = ความคลาดเคลื่อนแปลงย่อย (Subplot Error)
การจัดลำดับปัจจัยลงในแปลง
แปลงใหญ่ (Main Plot): ปัจจัยที่ต้องใช้เครื่องจักรขนาดใหญ่, ระบบน้ำ, วิธีเตรียมดิน หรือปัจจัยที่สนใจน้อยกว่า

แปลงย่อย (Subplot): ปัจจัยที่มีความสำคัญสูงสุดในงานวิจัย, สายพันธุ์พืช, หรือสูตรปุ๋ยเคมีที่ต้องการความแม่นยำสูง
📌
ข้อสังเกต: ปัจจัยแปลงย่อย B ถูกทดสอบด้วย $MS_{E_b}$ ซึ่งมีขนาดเล็กกว่า $MS_{E_a}$ จึงตรวจพบความต่างได้ง่ายกว่า
TWO-STAGE PARTITION · การแยกผลรวมกำลังสอง

การแยกผลรวมกำลังสอง 2 ระดับใน Split-Plot

ความแปรปรวนรวม ($SS_{\text{Total}}$) ถูกผ่าออกเป็น 2 ส่วนตามจังหวะของการสุ่ม:

ส่วนที่ 1: แปลงใหญ่ (Whole-Plot)
  • $SS_{\text{Block}} = \frac{\sum Y_{\cdot j\cdot}^2}{ab} - CF, \quad df = r - 1$
  • $SS_A = \frac{\sum Y_{i\cdot\cdot}^2}{br} - CF, \quad df = a - 1$
  • $SS_{E_a} = \frac{\sum \sum Y_{ij\cdot}^2}{b} - CF - SS_{\text{Block}} - SS_A$
  • $df_{E_a} = (a - 1)(r - 1)$ (องศาอิสระ Error แปลงใหญ่)
ส่วนที่ 2: แปลงย่อย (Subplot)
  • $SS_B = \frac{\sum Y_{\cdot\cdot k}^2}{ar} - CF, \quad df = b - 1$
  • $SS_{AB} = \frac{\sum \sum Y_{i\cdot k}^2}{r} - CF - SS_A - SS_B, \quad df = (a-1)(b-1)$
  • $SS_{E_b} = SS_{\text{Total}} - (\text{ทุกก้อนข้างต้น})$
  • $df_{E_b} = a(r - 1)(b - 1)$ (องศาอิสระ Error แปลงย่อย)
💡
สมบัติการบวก: $SS_{\text{Total}} = SS_{\text{Block}} + SS_A + SS_{E_a} + SS_B + SS_{AB} + SS_{E_b}$ มี $df_{\text{Total}} = rab - 1$

HISTORICAL VIGNETTE · ประวัติศาสตร์สถิติโลก

เรื่องเล่าประวัติศาสตร์: คลองส่งน้ำชลประทาน & แปลงปุ๋ยย่อยสองจังหวะ

"เราไม่สามารถขับรถแทรกเตอร์หรือเปลี่ยนระดับน้ำในคลองชลประทานทุกๆ 2 เมตรได้... ปัจจัยใหญ่ต้องคุมทั้งแปลง!"

ในงานเกษตรกรรม ปัจจัยบางอย่างต้องใช้พื้นที่กว้างและเปลี่ยนระดับได้ยากมาก เช่น ระบบน้ำหรือการไถพรวน (Main Plot) ขณะที่พันธุ์พืชหรือปุ๋ยสามารถหยอดแบ่งในแปลงย่อยได้ง่าย (Subplot) ฟิชเชอร์และเยตส์จึงคิดค้น Split-Plot ซึ่งนำไปสู่การสุ่มสองจังหวะและทำให้เกิดความคลาดเคลื่อน 2 ตัวในตารางเดียว

บทเรียนสำคัญสู่ทฤษฎี
ข้อจำกัดทางกายภาพและวิศวกรรมเกษตรเป็นตัวกำหนดแผนแบบการทดลอง Split-Plot เกิดขึ้นเพื่อประนีประนอมระหว่างความเป็นไปได้จริงกับความถูกต้องทางสถิติ
REAL CASE STUDY · การทดลองจริงภาคสนาม

กรณีศึกษาจริง: ระบบการจัดการดิน (Main) ร่วมกับสายพันธุ์ข้าว (Subplot)

บริบทและการประยุกต์ใช้ในไทย
แปลงใหญ่คือวิธีเตรียมดิน 3 แบบ (ไถดะ, ไถแปร, ไม่ไถ) ซึ่งต้องใช้แทรกเตอร์ขนาดใหญ่ทำทั้งแปลง จากนั้นในแต่ละแปลงใหญ่แบ่งเป็น 4 แปลงย่อยเพื่อปลูกข้าว 4 พันธุ์ การทดสอบพันธุ์ข้าว (Subplot) จะมีความแม่นยำสูงกว่าการทดสอบการเตรียมดิน เพราะมี Error_b ที่เล็กกว่า
คำแนะนำสำหรับวิทยานิพนธ์

หากงานวิจัยของท่านเน้นที่สายพันธุ์ข้าว จงนำสายพันธุ์ข้าวไปไว้ที่ Subplot เสมอ เพราะจะได้รับการทดสอบด้วย Error Term ที่เล็กที่สุดและมี df สูงสุด

INTERACTIVE LAB · แบบจำลองสถานการณ์จริง

ห้องทดลองจำลองเชิงโต้ตอบประจำบทเรียน

ระดับความคลาดเคลื่อน 2 ชั้น
Main Plot Error (E_a): ความคลาดเคลื่อนแปลงใหญ่ (หยาบกว่า)

Subplot Error (E_b): ความคลาดเคลื่อนแปลงย่อย (ละเอียดกว่า)
แหล่งความแปรปรวนตัวเศษตัวหารที่ถูกต้องความแม่นยำ
Main Plot Factor A (ระบบน้ำ)MS_AMS_Eaต่ำกว่า (แปลงกว้าง)
Subplot Factor B (พันธุ์พืช)MS_BMS_Ebสูงกว่า (แปลงย่อยละเอียด)
Interaction A x BMS_ABMS_Ebสูงกว่า
ห้ามยุบ MS_Ea กับ MS_Eb รวมกันเด็ดขาด เพราะโครงสร้างการสุ่มเกิดขึ้นคนละระดับ!
WORKED EXAMPLE · ตัวอย่างการคำนวณจริง

ตัวอย่างการคำนวณ Split-Plot Design ในแปลงข้าว

การทดลองเตรียมดิน 3 แบบ ($a=3$) $\times$ พันธุ์ข้าว 2 พันธุ์ ($b=2$) จัดใน $r=3$ บล็อก ($N=18$):

1. การวิเคราะห์ส่วนแปลงใหญ่ (Main Plot)
  • $SS_{\text{Block}} = 24.0 \quad (df = 3 - 1 = 2)$
  • $SS_A = 90.0 \quad (df = 3 - 1 = 2) \implies MS_A = 45.0$
  • $SS_{E_a} = 36.0 \quad (df = (3 - 1)(3 - 1) = 4) \implies MS_{E_a} = 9.0$
  • ทดสอบแปลงใหญ่ A: $$F_A = \frac{MS_A}{MS_{E_a}} = \frac{45.0}{9.0} = 5.00$$
  • เทียบ $F_{0.05, 2, 4} = 6.94 \implies F_A < 6.94$ (ไม่ Sig!)
2. การวิเคราะห์ส่วนแปลงย่อย (Subplot)
  • $SS_B = 60.0 \quad (df = 2 - 1 = 1) \implies MS_B = 60.0$
  • $SS_{AB} = 64.0 \quad (df = 2 \times 1 = 2) \implies MS_{AB} = 32.0$
  • $SS_{E_b} = 32.0 \quad (df = 3(3-1)(2-1) = 8) \implies MS_{E_b} = 4.0$
  • ทดสอบแปลงย่อย B: $F_B = \frac{60.0}{4.0} = 15.00 > F_{0.05, 1, 8} = 5.32$ (Sig!)
  • ทดสอบ Interaction: $F_{AB} = \frac{32.0}{4.0} = 8.00 > F_{0.05, 2, 8} = 4.46$ (Sig!)
📊
ข้อสังเกต: ปัจจัย B และ AB มีความไวในการตรวจพบสูงมากเพราะ $MS_{E_b} = 4.0$ เล็กกว่า $MS_{E_a} = 9.0$ เกินครึ่งหนึ่ง
FORENSIC AUDIT · คดีสืบสวนข้อผิดพลาด

แฟ้มคดีอาชญากรรมทางสถิติ: 3 กับดักยอดฮิต

ตรวจสอบงานวิจัยของท่านด้วย Checklist วินิจฉัยนี้ก่อนลงมือปฏิบัติจริง:

CASE 01
ยุบ Error_a รวมกับ Error_b เป็นก้อนเดียว (The Single Error Disaster): วิเคราะห์ Split-Plot เสมือน Factorial ธรรมดา โดยหารทุกอย่างด้วย Error ก้อนเดียว ทำให้ทดสอบ Main Plot ไวเกินจริงอย่างร้ายแรง
CASE 02
เอาปัจจัยที่สนใจมากที่สุดไปไว้ที่ Main Plot: นำปัจจัยหลักของวิทยานิพนธ์ไปวางไว้ในแปลงใหญ่ ทั้งที่ Main Plot มีความแม่นยำต่ำกว่า Subplot ควรเอาปัจจัยสำคัญไว้ที่ Subplot
CASE 03
ใช้ Standard Error ผิดสูตรในการเปรียบเทียบค่าเฉลี่ย: Split-Plot มีสูตร SE ถึง 4 รูปแบบขึ้นกับคู่เปรียบเทียบ (ใน Main เดียวกัน vs ต่าง Main Plot) ผู้วิจัยมักจำสูตรเดียวไปใช้ทั้งหมด
🔍
หลักการเตือนใจ: เมื่อเปรียบเทียบค่าเฉลี่ยของทรีตเมนต์ใน Split-Plot ต้องระบุให้ชัดว่าเป็นผลต่างภายใต้ Main Plot เดียวกัน (ใช้ $E_b$) หรือต่าง Main Plot (ต้องรวม $E_a$ และ $E_b$ ด้วย Satterthwaite formula)
