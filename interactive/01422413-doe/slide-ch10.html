MODULE 10 · SPLIT-PLOT DESIGN

บทที่ 10: แผนการทดลองแบบสปลิท-พลอท (Split-Plot)

เรียนรู้โครงสร้างทางสถิติ การวางผังแปลง การทดสอบสมมติฐานทางคณิตศาสตร์ และการแปลผลการวิจัยจริงอย่างถูกต้องตามมาตรฐานสากล

โครงสร้าง Error2 ระดับ: Error_a และ Error_b
Main Plotปัจจัยที่เปลี่ยนยาก (คลอง/รถไถ)
Subplotปัจจัยที่เปลี่ยนง่าย (ปุ๋ย/พันธุ์)
การสุ่มTwo-Stage Randomization
1. วัตถุประสงค์หลัก
ทำความเข้าใจตัวแบบเชิงเส้นทางสถิติ ($y$) และการสุ่มจัดสรรทรีตเมนต์ลงสู่หน่วยทดลองอย่างถูกต้อง
2. การวิเคราะห์ ANOVA
แยกผลรวมกำลังสอง ($SS$) คำนวณองศาอิสระ ($df$) และทดสอบอัตราส่วนความแปรปรวน ($F$-test)
3. การประยุกต์ใช้งาน
เชื่อมโยงสู่การทำโครงงาน วิจัยเกษตรกรรม อุตสาหกรรมชีวภาพ และการเขียนวิทยานิพนธ์ระดับบัณฑิตศึกษา
STATISTICAL FORMULATION · ตัวแบบทางสถิติ

ตัวแบบเชิงเส้นและข้อกำหนดทางคณิตศาสตร์

ตัวแบบทางสถิติของแผนแบบนี้ สะท้อนแหล่งที่มาของความแปรปรวนที่ผู้วิจัยต้องการศึกษาและส่วนที่ควบคุม:

สมการตัวแบบเชิงเส้น (Linear Model)
$$y_{ij} = \mu + au_i + arepsilon_{ij}$$
  • $y_{ij}$ = ค่าสังเกตของหน่วยทดลองที่ได้รับทรีตเมนต์ $i$ ซ้ำที่ $j$
  • $\mu$ = ค่าเฉลี่ยรวมแท้จริง (Overall True Mean)
  • $ au_i$ = อิทธิพลของทรีตเมนต์ที่ $i$ โดย $\sum au_i = 0$ (Fixed Effect)
  • $ arepsilon_{ij}$ = ความคลาดเคลื่อนสุ่ม โดย $ arepsilon_{ij} \sim ext{NID}(0, \sigma^2)$
ข้อสมมติฐานและเงื่อนไขบังคับ
  • Independence: ความคลาดเคลื่อนระหว่างหน่วยทดลองต้องเป็นอิสระต่อกัน (รับประกันด้วยการสุ่ม)
  • Normality: เศษเหลือต้องมีการแจกแจงแบบปกติ
  • Homoscedasticity: ความแปรปรวนของความคลาดเคลื่อนต้องคงที่ทุกกลุ่ม ($\sigma_1^2 = \sigma_2^2 = \dots = \sigma^2$)
📌
ข้อสังเกต: หากข้อสมมติความเป็นเนื้อเดียวกันของความแปรปรวนถูกละเมิด ค่า $F$-test จะเกิดความคลาดเคลื่อนสูงมาก ต้องแปลงข้อมูลก่อนวิเคราะห์
VARIANCE DECOMPOSITION · การแยกส่วนความแปรปรวน

การแยกผลรวมกำลังสอง (Sum of Squares)

หัวใจของ ANOVA คือการผ่าความแปรปรวนรวม ($SS_{\text{Total}}$) ออกเป็นก้อนที่อธิบายได้และก้อนความคลาดเคลื่อน:

สูตรการแยกผลรวมกำลังสอง
$$SS_{\text{Total}} = SS_{\text{Tr}} + SS_E$$ $$\sum_{i=1}^t \sum_{j=1}^r (y_{ij} - \bar{y}_{\cdot\cdot})^2 = r\sum_{i=1}^t (\bar{y}_{i\cdot} - \bar{y}_{\cdot\cdot})^2 + \sum_{i=1}^t \sum_{j=1}^r (y_{ij} - \bar{y}_{i\cdot})^2$$
การแบ่งสรรองศาความเป็นอิสระ (df)
  • $df_{\text{Total}} = N - 1 = tr - 1$
  • $df_{\text{Tr}} = t - 1$ (จำนวนทรีตเมนต์ลบ 1)
  • $df_E = t(r - 1) = N - t$ (องศาอิสระเพื่อประมาณค่า $\sigma^2$)
💡
กฎอนุรักษ์: ทั้งผลรวมกำลังสอง ($SS$) และองศาอิสระ ($df$) สามารถบวกกันได้เสมอ: $SS_{\text{Total}} = \sum SS_{\text{Components}}$
ANOVA TABLE · โครงสร้างตารางวิเคราะห์

ตารางวิเคราะห์ความแปรปรวนและสถิติทดสอบ $F$

รวบรวมค่าจากการแยกส่วนความแปรปรวนเพื่อคำนวณอัตราส่วนทดสอบ $F = MS_{\text{Tr}} / MS_E$:

เกณฑ์ตัดสินใจ: ปฏิเสธ $H_0$ เมื่อ $F_{\text{calc}} > F_{\alpha, t-1, N-t}$ แปลว่ามีทรีตเมนต์อย่างน้อย 1 คู่ที่มีค่าเฉลี่ยแตกต่างกันอย่างมีนัยสำคัญทางสถิติ
HISTORICAL VIGNETTE · ประวัติศาสตร์สถิติโลก

เรื่องเล่าประวัติศาสตร์: คลองส่งน้ำชลประทาน & แปลงปุ๋ยย่อยสองจังหวะ

"เราไม่สามารถขับรถแทรกเตอร์หรือเปลี่ยนระดับน้ำในคลองชลประทานทุกๆ 2 เมตรได้... ปัจจัยใหญ่ต้องคุมทั้งแปลง!"

ในงานเกษตรกรรม ปัจจัยบางอย่างต้องใช้พื้นที่กว้างและเปลี่ยนระดับได้ยากมาก เช่น ระบบน้ำหรือการไถพรวน (Main Plot) ขณะที่พันธุ์พืชหรือปุ๋ยสามารถหยอดแบ่งในแปลงย่อยได้ง่าย (Subplot) ฟิชเชอร์และเยตส์จึงคิดค้น Split-Plot ซึ่งนำไปสู่การสุ่มสองจังหวะและทำให้เกิดความคลาดเคลื่อน 2 ตัวในตารางเดียว

บทเรียนสำคัญสู่ทฤษฎี
ประวัติศาสตร์สอนเราว่า สถิติไม่ได้เกิดขึ้นในห้องแอร์ แต่เกิดจากการแก้ปัญหาจริงในแปลงเกษตร โรงเบียร์ และโรงงานอุตสาหกรรม ความถูกต้องของการทดลองเริ่มต้นจากการจัดผังแปลง ไม่ใช่การคำนวณหลังเก็บข้อมูลเสร็จแล้ว
REAL CASE STUDY · การทดลองจริงภาคสนาม

กรณีศึกษาจริง: ระบบการจัดการดิน (Main) ร่วมกับสายพันธุ์ข้าว (Subplot)

บริบทและการประยุกต์ใช้ในไทย
แปลงใหญ่คือวิธีเตรียมดิน 3 แบบ (ไถดะ, ไถแปร, ไม่ไถ) ซึ่งต้องใช้แทรกเตอร์ขนาดใหญ่ทำทั้งแปลง จากนั้นในแต่ละแปลงใหญ่แบ่งเป็น 4 แปลงย่อยเพื่อปลูกข้าว 4 พันธุ์ การทดสอบพันธุ์ข้าว (Subplot) จะมีความแม่นยำสูงกว่าการทดสอบการเตรียมดิน เพราะมี Error_b ที่เล็กกว่า
คำแนะนำสำหรับวิทยานิพนธ์

นิสิตวิทยาเขตกำแพงแสนต้องจำไว้เสมอ: "ผังแปลงกระดาษต้องแปลงเป็นผังจริงบนดินได้" ระวังขอบแปลง (Border Effect), ความลาดชันของน้ำ, และทิศทางร่มเงาไม้ใหญ่เสมอ

INTERACTIVE LAB · แบบจำลองสถานการณ์จริง

ห้องทดลองจำลองเชิงโต้ตอบประจำบทเรียน

ระดับความคลาดเคลื่อน 2 ชั้น
Main Plot Error (E_a): ความคลาดเคลื่อนแปลงใหญ่ (หยาบกว่า)

Subplot Error (E_b): ความคลาดเคลื่อนแปลงย่อย (ละเอียดกว่า)

WORKED NUMERICAL EXAMPLE · ตัวอย่างการคำนวณจริง

ตัวอย่างการคำนวณตาราง ANOVA แบบทีละขั้นตอน

สมมติข้อมูล $t = 4$ ทรีตเมนต์ และ $r = 4$ ซ้ำ ($N = 16$ แปลง) คำนวณได้ผลรวมดังนี้:

1. คำนวณค่า Correction Factor และ SS
  • $CF = \frac{Y_{\cdot\cdot}^2}{N} = \frac{800^2}{16} = 40,000.0$
  • $SS_{\text{Total}} = \sum y_{ij}^2 - CF = 40,320.0 - 40,000.0 = 320.0$
  • $SS_{\text{Tr}} = \frac{\sum Y_{i\cdot}^2}{r} - CF = 40,240.0 - 40,000.0 = 240.0$
  • $SS_E = SS_{\text{Total}} - SS_{\text{Tr}} = 320.0 - 240.0 = 80.0$
2. สรุปผลตาราง ANOVA
  • $MS_{\text{Tr}} = \frac{240.0}{3} = 80.0$
  • $MS_E = \frac{80.0}{12} = 6.67$
  • $F_{\text{calc}} = \frac{80.0}{6.67} = 12.00$
  • $F_{0.05, 3, 12} = 3.49 \implies F_{\text{calc}} > 3.49$ (แตกต่างอย่างมีนัยสำคัญ!)
FORENSIC AUDIT · คดีสืบสวนข้อผิดพลาด

แฟ้มคดีอาชญากรรมทางสถิติ: 3 กับดักยอดฮิต

ตรวจสอบงานวิจัยของท่านด้วย Checklist วินิจฉัยนี้ก่อนลงมือปฏิบัติจริง:

CASE 01
ยุบ Error_a รวมกับ Error_b เป็นก้อนเดียว (The Single Error Disaster): วิเคราะห์ Split-Plot เสมือน Factorial ธรรมดา โดยหารทุกอย่างด้วย Error ก้อนเดียว ทำให้ทดสอบ Main Plot ไวเกินจริงอย่างร้ายแรง
CASE 02
เอาปัจจัยที่สนใจมากที่สุดไปไว้ที่ Main Plot: นำปัจจัยหลักของวิทยานิพนธ์ไปวางไว้ในแปลงใหญ่ ทั้งที่ Main Plot มีความแม่นยำต่ำกว่า Subplot ควรเอาปัจจัยสำคัญไว้ที่ Subplot
CASE 03
ใช้ Standard Error ผิดสูตรในการเปรียบเทียบค่าเฉลี่ย: Split-Plot มีสูตร SE ถึง 4 รูปแบบขึ้นกับคู่เปรียบเทียบ (ใน Main เดียวกัน vs ต่าง Main Plot) ผู้วิจัยมักจำสูตรเดียวไปใช้ทั้งหมด
🔍
หลักการเตือนใจ: ตรวจสอบข้อตกลงเบื้องต้นและตัวหาร F เสมอ หากวางแผนผิดตั้งแต่ผังแปลง สถิติขั้นสูงใดๆ ก็ไม่สามารถกู้ข้อมูลกลับมาได้
ROADMAP · สรุปและก้าวถัดไป

สิ่งสำคัญที่ได้เรียนรู้
  • เข้าใจตัวแบบและข้อตกลงของ แผนการทดลองแบบสปลิท-พลอท (Split-Plot) อย่างลึกซึ้ง
