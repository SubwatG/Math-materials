MODULE 07 · NESTED / HIERARCHICAL DESIGN

บทที่ 7: แผนการทดลองแบบสุ่มซ้อน (Nested Design)

เมื่อปัจจัยหนึ่งซ้อนอยู่ภายในอีกปัจจัยหนึ่งเป็นลำดับชั้น เช่น แบทช์ในโรงงาน หรือคอกลูกสัตว์ในแม่พันธุ์ ตัวหาร F-ratio จะเปลี่ยนไปตามหลัก Expected Mean Squares (EMS)

ตัวแบบy_{ijk} = \mu + A_i + B_{j(i)} + \varepsilon_{k(ij)}
ความสัมพันธ์B ซ้อนอยู่ใน A (Not Crossed)
ตัวหาร F ของ AMS_{B(A)} (ห้ามใช้ MS_E!)
การประยุกต์การควบคุมคุณภาพอุตสาหกรรม
1. ลำดับชั้นซ้อนใน
ระดับของปัจจัย B ภายใต้ทรีตเมนต์ A หนึ่ง ไม่มีความเกี่ยวข้องใดๆ กับระดับของ B ภายใต้ทรีตเมนต์ A อื่น
2. ไม่มี Interaction
เนื่องจากปัจจัยไม่ได้ตัดข้ามกัน (Not Crossed) จึงไม่มีพจน์ $A \times B$ ปรากฏในตัวแบบ มีแต่พจน์ซ้อน $B(A)$
3. กับดักตัวหาร EMS
หาก B เป็นปัจจัยสุ่ม การทดสอบอิทธิพลของ A ต้องหารด้วย $MS_{B(A)}$ ไม่ใช่ $MS_E$ นี่คือจุดผิดอันดับหนึ่ง!
HIERARCHICAL MODEL · ตัวแบบสุ่มซ้อน

ตัวแบบเชิงเส้นของ Two-Stage Nested Design

ตัวแบบเชิงเส้นสำหรับการทดลองสุ่มซ้อนสองจังหวะ (B ซ้อนอยู่ใน A):

สมการตัวแบบเชิงเส้น (Linear Model)
$$y_{ijk} = \mu + A_i + B_{j(i)} + \varepsilon_{k(ij)}$$ โดย $i=1..a, j=1..b, k=1..n$
  • $y_{ijk}$ = ค่าสังเกตของหน่วยย่อยที่ $k$ ในกลุ่ม $j$ ภายใต้ทรีตเมนต์ $i$
  • $A_i$ = อิทธิพลของปัจจัยหลัก A (Stage 1)
  • $B_{j(i)}$ = อิทธิพลของปัจจัย B ที่ซ้อนอยู่ในระดับ $A_i$ (Stage 2)
  • $\varepsilon_{k(ij)} \sim \text{NID}(0, \sigma^2)$ = ความคลาดเคลื่อนสุ่มระหว่างหน่วยย่อย
ความแตกต่างระหว่าง Nested กับ Factorial
Factorial (A x B): ทรีตเมนต์ตัดข้ามกัน แบทช์ 1 ในโรงงาน A มีความหมายเทียบเท่ากับแบทช์ 1 ในโรงงาน B มีพจน์ $AB$

Nested (B in A): แบทช์ 1 ในโรงงาน A เป็นคนละวัตถุดิบกับแบทช์ 1 ในโรงงาน B โดยสิ้นเชิง จึงไม่มี $AB$ แต่เป็น $B(A)$
📌
หลักจำง่าย: ถ้าสลับระดับของ B ข้ามกลุ่ม A แล้วความหมายเดิมหายไป นั่นคือแผนแบบสุ่มซ้อน (Nested Design)
SS DECOMPOSITION · การแยกผลรวมกำลังสอง

การแยกผลรวมกำลังสองและองศาอิสระใน Nested

ใน Nested Design ความแปรปรวนรวม ($SS_{\text{Total}}$) ถูกแยกออกเป็น 3 ส่วนตามลำดับชั้น:

สูตรการคำนวณ Sums of Squares
$$SS_{\text{Total}} = SS_A + SS_{B(A)} + SS_E$$
$$CF = \frac{Y_{\cdot\cdot\cdot}^2}{abn}, \quad SS_{\text{Total}} = \sum \sum \sum y_{ijk}^2 - CF$$
$$SS_A = \frac{\sum Y_{i\cdot\cdot}^2}{bn} - CF$$
$$SS_{B(A)} = \frac{\sum \sum Y_{ij\cdot}^2}{n} - \frac{\sum Y_{i\cdot\cdot}^2}{bn}, \quad SS_E = SS_{\text{Total}} - \frac{\sum \sum Y_{ij\cdot}^2}{n}$$
การกระจายองศาความเป็นอิสระ (df)
  • $df_{\text{Total}} = abn - 1$
  • $df_A = a - 1$ (จำนวนระดับของ A ลบ 1)
  • $df_{B(A)} = a(b - 1)$ (จำนวนซ้ำ B ภายใน A)
  • $df_E = ab(n - 1)$ (ความผันแปรระหว่างหน่วยย่อย)
  • สมบัติบวก: $abn-1 = (a-1) + a(b-1) + ab(n-1)$
💡
ข้อสังเกต: $SS_{B(A)}$ เกิดจากการรวมผลรวมกำลังสองของ B ภายในแต่ละกลุ่ม A เข้าด้วยกัน: $\sum_{i=1}^a SS_{B \text{ in } A_i}$

HISTORICAL VIGNETTE · ประวัติศาสตร์สถิติโลก

เรื่องเล่าประวัติศาสตร์: โรงงานผลิตยา 3 แห่ง สู่การค้นหาความคลาดเคลื่อนสองชั้น

"แบทช์ที่ 1 ในโรงงานเชียงใหม่ ไม่มีความเกี่ยวข้องใดๆ ทั้งสิ้นกับแบทช์ที่ 1 ในโรงงานระยอง!"

ในงานวิจัยเภสัชกรรมและวิศวกรรม บริษัทสุ่มตรวจยาจากโรงงาน 3 แห่ง แต่ละโรงงานสุ่มมา 2 แบทช์ และแต่ละแบทช์สุ่มตรวจยา 4 เม็ด นี่คือโครงสร้างแบบลำดับชั้น (Hierarchical) แบทช์ไม่ได้ตัดข้ามกันแบบ Factorial จึงไม่มีพจน์ Interaction A x B แต่เป็น B ซ้อนใน A หรือ B(A)

บทเรียนสำคัญสู่ทฤษฎี
การระบุความสัมพันธ์ของปัจจัยว่าเป็นการตัดข้าม (Crossed) หรือการซ้อนใน (Nested) มีผลชี้ขาดต่อโครงสร้างตาราง ANOVA และการเลือกตัวหาร F-ratio
REAL CASE STUDY · การทดลองจริงภาคสนาม

กรณีศึกษาจริง: การประเมินพันธุกรรมแม่พันธุ์ปลานิลและลูกปลาในคอก

บริบทและการประยุกต์ใช้ในไทย
สุ่มแม่พันธุ์ปลานิลมา 4 แม่ แต่ละแม่ให้ลูกปลา 3 คอก และสุ่มลูกปลามาคอกละ 5 ตัวเพื่อวัดน้ำหนัก คอกปลาเป็นปัจจัยที่ซ้อนอยู่ในแม่พันธุ์ปลาแต่ละตัว การทดสอบว่าแม่พันธุ์ปลาส่งผลต่อน้ำหนักลูกปลาหรือไม่ ต้องเทียบกับความแปรปรวนระหว่างคอก MS_B(A) ไม่ใช่ความแปรปรวนของลูกปลาในคอก MS_E
คำแนะนำสำหรับวิทยานิพนธ์

หากลูกปลาแต่ละตัวมาจากคอกเดียวกัน อิทธิพลสิ่งแวดล้อมในคอกจะทำให้ลูกปลาในคอกเดียวกันคล้ายกัน การหารด้วย MS_E จะทำให้เกิด Pseudoreplication ทันที

WORKED EXAMPLE · ตัวอย่างการคำนวณจริง

ตัวอย่างการคำนวณ Nested Design ในโรงงานยา

สุ่มตรวจโรงงานผลิตยา $a=3$ แห่ง, สุ่มตรวจแบทช์ละ $b=2$ แบทช์, แต่ละแบทช์วัดยา $n=4$ เม็ด ($N=24$):

1. การคำนวณตาราง ANOVA ของ Nested
  • $SS_A = 120.0 \quad (df = 3 - 1 = 2)$
  • $SS_{B(A)} = 60.0 \quad (df = 3(2 - 1) = 3)$
  • $SS_E = 36.0 \quad (df = 3 \times 2 \times (4 - 1) = 18)$
  • $SS_{\text{Total}} = 120.0 + 60.0 + 36.0 = 216.0$
  • $MS_A = 120.0 / 2 = 60.0$
  • $MS_{B(A)} = 60.0 / 3 = 20.0, \quad MS_E = 36.0 / 18 = 2.0$
2. การทดสอบสมมติฐานและตัวหารที่ถูกต้อง
  • ทดสอบแบทช์ $B(A)$: $F_{B(A)} = \frac{MS_{B(A)}}{MS_E} = \frac{20.0}{2.0} = 10.00 > F_{0.05, 3, 18} = 3.16$ (Sig!)
  • ทดสอบโรงงาน A (ตัวหารที่ถูก): $F_A = \frac{MS_A}{MS_{B(A)}} = \frac{60.0}{20.0} = 3.00 < F_{0.05, 2, 3} = 9.55$ (ไม่ Sig!)
  • ถ้าใช้ตัวหารผิด ($MS_E$): $F_A = \frac{60.0}{2.0} = 30.00$ จะสรุปผิดว่าโรงงานต่างกัน ทั้งที่เป็นเพียงความผันแปรระหว่างแบทช์!
📊
บทเรียนราคาแพง: การใช้ตัวหารผิดใน Nested Design จะเปลี่ยนข้อสรุปจาก 'ไม่แตกต่าง' เป็น 'แตกต่างมหาศาล' ได้ทันที
FORENSIC AUDIT · คดีสืบสวนข้อผิดพลาด

แฟ้มคดีอาชญากรรมทางสถิติ: 3 กับดักยอดฮิต

ตรวจสอบงานวิจัยของท่านด้วย Checklist วินิจฉัยนี้ก่อนลงมือปฏิบัติจริง:

CASE 01
วิเคราะห์ Nested เสมือนเป็น Factorial A x B: สร้างตาราง ANOVA โดยใส่พจน์ A x B ลงไป ทั้งที่ระดับของปัจจัย B ในแต่ละ A เป็นคนละตัวกันโดยสิ้นเชิง
CASE 02
ใช้ MS_E เป็นตัวหารทดสอบปัจจัยหลัก A (The Fatal Denominator Trap): นำ MS_A / MS_E เพื่อหาค่า F ส่งผลให้ค่า F สูงเกินจริงอย่างมหาศาล สรุปผลว่าทรีตเมนต์ต่าง ทั้งที่เป็นเพียงความผันแปรระหว่างแบทช์
CASE 03
ไม่เข้าใจ Expected Mean Squares (EMS): จำตารางตัวหารผิดเมื่อโมเดลเปลี่ยนเป็น Random Model หรือ Mixed Model ทำให้สรุปผลการทดสอบ F ผิดยกตาราง
🔍
หลักการเตือนใจ: เขียนสมการตัวแบบเชิงเส้นและตาราง EMS ทุกครั้งก่อนกดรันโปรแกรมสถิติ เพื่อตรวจสอบว่าโปรแกรมเลือกตัวหาร Error Term ถูกต้องหรือไม่
