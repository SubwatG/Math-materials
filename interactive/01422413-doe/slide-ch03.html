1. ปัญหา FWE
การทดสอบ t-test ซ้ำหลายคู่ จะทำให้ความน่าจะเป็นที่จะเกิดผลบวกลวงสะสมพุ่งสูงเกินเกณฑ์ 0.05 อย่างรวดเร็ว
2. การเลือกวิธีทดสอบ
Tukey HSD เหมาะกับทุกคู่, Dunnett เหมาะกับเทียบ Control, และ Scheffé เหมาะกับ Contrast เชิงเส้นซับซ้อน
3. การสรุปกลุ่มตัวอักษร
การจัดกลุ่มค่าเฉลี่ยด้วยขีดเส้นใต้หรือตัวอักษร a, b, c ช่วยสื่อสารผลการวิจัยทางวิชาการได้อย่างกระชับและเป็นสากล
PAIRWISE INFLATION · อัตราความคลาดเคลื่อนสะสม

ปัญหา Family-Wise Error และประเภทการเปรียบเทียบ

เมื่อ F-test พบความแตกต่างอย่างมีนัยสำคัญ การทดสอบทีละคู่จะเกิดปัญหาร้ายแรงหากไม่ควบคุมความผิดพลาดรวม:

การพุ่งสูงของ Family-Wise Error Rate (FWE)
$$\alpha_{FW} = 1 - (1 - \alpha)^k, \quad k = \binom{t}{2}$$ ถ้าทดสอบ $t=5$ ทรีตเมนต์ จะมี $k=10$ คู่ หากใช้ $\alpha=0.05$ ทุกคู่:
$$\alpha_{FW} = 1 - (0.95)^{10} \approx 0.401$$ (คิดเป็น 40.1%!)
แปลว่ามีโอกาสถึง 40% ที่จะเกิดผลบวกลวง (Type I Error) อย่างน้อย 1 คู่!
A Priori vs Post-Hoc Comparisons
1. ก่อนการทดลอง (A Priori / Planned): วางแผนเปรียบเทียบเฉพาะคู่ที่สนใจไว้ล่วงหน้า เช่น การเปรียบเทียบความเปรียบต่างเชิงตั้งฉาก (Orthogonal Contrasts)

2. หลังการทดลอง (Post-Hoc / Unplanned): ทดสอบทุกคู่ที่เป็นไปได้หลังจาก $F$-test ปฏิเสธ $H_0$ เช่น Tukey's HSD, Scheffé's Test
📌
ข้อควรระวัง: การใช้ Fisher's LSD เปรียบเทียบทุกคู่โดยไม่ปรับ $\alpha$ จะทำให้ระดับนัยสำคัญรวมล้มเหลว
ORTHOGONAL CONTRASTS · ทฤษฎีความเปรียบต่าง

ความเปรียบต่างเชิงตั้งฉาก (Orthogonal Contrasts)

การเปรียบเทียบที่มีแบบแผนล่วงหน้า ช่วยให้แยกผลรวมกำลังสองของทรีตเมนต์ ($SS_{\text{Tr}}$) ออกเป็นส่วนย่อยที่เป็นอิสระต่อกัน:

นิยามและความเป็นอิสระเชิงเส้น
ความเปรียบต่าง $C = \sum_{i=1}^t c_i \bar{y}_{i\cdot}$ โดยมีเงื่อนไข $\sum_{i=1}^t c_i = 0$
ความเปรียบต่าง 2 ชุด $C_1, C_2$ จะตั้งฉากกัน (Orthogonal) ก็ต่อเมื่อ:
$$\sum_{i=1}^t \frac{c_{1i} c_{2i}}{r_i} = 0 \quad (\text{หรือ } \sum c_{1i} c_{2i} = 0 \text{ เมื่อ } r \text{ เท่ากัน})$$
การแยก SS ของ Contrast
แต่ละ Contrast ที่ตั้งฉากกันมี $df = 1$ และมีผลรวมกำลังสองคือ:
$$SS_C = \frac{(\sum c_i Y_{i\cdot})^2}{r \sum c_i^2}$$
เราสามารถแยก $SS_{\text{Tr}}$ ออกเป็น $t-1$ Contrasts ที่เป็นอิสระต่อกันได้อย่างสมบูรณ์: $SS_{\text{Tr}} = \sum_{m=1}^{t-1} SS_{C_m}$
💡
การทดสอบ F: สถิติทดสอบ $F_C = \frac{MS_C}{MS_E} = \frac{SS_C}{MS_E}$ เทียบกับ $F_{\alpha, 1, df_E}$
COMPARISON CRITERIA · เกณฑ์การทดสอบพหุคูณ

ตารางเปรียบเทียบ 4 วิธีทดสอบพหุคูณยอดนิยม

เลือกใช้วิธีทดสอบให้เหมาะสมกับวัตถุประสงค์และโครงสร้างการทดลอง:

วิธีทดสอบสูตรระยะวิกฤต (Critical Yardstick)สถานการณ์ที่เหมาะสมระดับความเข้มงวด
Fisher's LSD$LSD = t_{\alpha/2, df_E} \sqrt{\frac{2MS_E}{r}}$เปรียบเทียบไม่กี่คู่วางแผนล่วงหน้าต่ำสุด (เสี่ยง Type I)
Tukey's HSD$HSD = q_{\alpha, t, df_E} \sqrt{\frac{MS_E}{r}}$เปรียบเทียบทุกคู่ ($r$ เท่ากัน)ปานกลาง (คุม FWE แม่นยำ)
Dunnett's Test$d' = d_{\alpha, t-1, df_E} \sqrt{\frac{2MS_E}{r}}$เปรียบเทียบกับกลุ่มควบคุม Controlเฉพาะเจาะจง (Power สูง)
Scheffé's Test$S = \sqrt{(t-1)F_{\alpha, t-1, df_E}} \sqrt{\frac{2MS_E}{r}}$เปรียบเทียบเชิงเส้นทุกรูปแบบเข้มงวดสูงสุด (Conservative)
🎯
คำแนะนำ: ในงานวิทยานิพนธ์ทั่วไปที่ต้องการเปรียบเทียบทุกคู่ แนะนำให้ใช้ Tukey's HSD เป็นมาตรฐานสากล
HISTORICAL VIGNETTE · ประวัติศาสตร์สถิติโลก

เรื่องเล่าประวัติศาสตร์: ศึกวิวาทะ Tukey vs Scheffé & ปรากฏการณ์ Jelly Bean

"ยิ่งคุณทดสอบเปรียบเทียบหลายคู่โดยไม่คุมความผิดพลาดรวม คุณก็ยิ่งกำลังหลอกตัวเองด้วยผลบวกลวง!"

จอห์น ทูกีย์ (John Tukey) พัฒนาวิธี Tukey HSD เพื่อแก้ปัญหาการพุ่งสูงของ Family-Wise Error Rate: ถ้าทดสอบ 10 คู่ โอกาสเจอผลบวกลวงพุ่งขึ้นสูงถึง 40%! ขณะที่ Henry Scheffé เสนอวิธีที่ปลอดภัยสูงสุดสำหรับการเปรียบเทียบเชิงเส้นทุกรูปแบบ แม้จะมีความเข้มงวดสูงกว่า

บทเรียนสำคัญสู่ทฤษฎี
การเลือกวิธีทดสอบพหุคูณต้องสอดคล้องกับวัตถุประสงค์ หากเป็นการสำรวจทั่วไป Tukey HSD คือคำตอบ แต่หากมีกลุ่มควบคุม Dunnett จะให้พลังการทดสอบดีกว่า
REAL CASE STUDY · การทดลองจริงภาคสนาม

บริบทและการประยุกต์ใช้ในไทย
การวิจัยผลิตภัณฑ์อาหารแปรรูป นำแป้งทอด 4 สูตรใหม่มาเปรียบเทียบกับสูตรมาตรฐานเดิม (Control) หากผู้วิจัยใช้ Tukey จะเป็นการทดสอบที่เข้มงวดเกินไป ในกรณีนี้ควรใช้ Dunnett's Test เพื่อเปรียบเทียบเฉพาะทรีตเมนต์กับกลุ่มควบคุม ซึ่งให้ Power สูงกว่าอย่างมาก
คำแนะนำสำหรับวิทยานิพนธ์

อย่าใช้ Tukey หรือ LSD พร่ำเพรื่อ หากโจทย์วิจัยระบุว่า 'เพื่อหาสูตรที่ดีกว่าสูตรดั้งเดิม' การใช้ Dunnett's test จะช่วยให้ค้นพบความต่างได้ง่ายขึ้นโดยไม่ผิดหลักสถิติ

WORKED EXAMPLE · ตัวอย่างการคำนวณจริง

ตัวอย่างการคำนวณ Tukey's HSD และการติดอักษรกลุ่ม

จากตัวอย่างบทที่ 2 ($t=4, r=4, MS_E = 5.00, df_E = 12$) ค่าเฉลี่ยพันธุ์คือ $\bar{y}_1=45.0, \bar{y}_2=55.0, \bar{y}_3=47.5, \bar{y}_4=52.5$:

1. คำนวณระยะวิกฤต HSD
  • เปิดตาราง Studentized Range $q_{0.05, 4, 12} = 4.199$
  • ความคลาดเคลื่อนมาตรฐานของค่าเฉลี่ย: $S_{\bar{y}} = \sqrt{\frac{MS_E}{r}} = \sqrt{\frac{5.00}{4}} = 1.118$
  • ระยะวิกฤต: $HSD = 4.199 \times 1.118 = 4.69$
  • เกณฑ์: หากผลต่าง $|\bar{y}_i - \bar{y}_j| \ge 4.69$ แปลว่าคู่นั้นต่างกันอย่างมีนัยสำคัญ
2. เปรียบเทียบผลต่างและการสรุปกลุ่มตัวอักษร
  • เรียงค่าเฉลี่ย: $\bar{y}_1 (45.0) < \bar{y}_3 (47.5) < \bar{y}_4 (52.5) < \bar{y}_2 (55.0)$
  • $|\bar{y}_2 - \bar{y}_1| = 10.0 \ge 4.69$ (Sig!)
  • $|\bar{y}_4 - \bar{y}_1| = 7.5 \ge 4.69$ (Sig!)
  • $|\bar{y}_3 - \bar{y}_1| = 2.5 < 4.69$ (ไม่ต่าง)
  • $|\bar{y}_2 - \bar{y}_4| = 2.5 < 4.69$ (ไม่ต่าง)
  • สรุปกลุ่ม: พันธุ์ 1 ($45.0^{\text{b}}$), พันธุ์ 3 ($47.5^{\text{b}}$), พันธุ์ 4 ($52.5^{\text{a}}$), พันธุ์ 2 ($55.0^{\text{a}}$)
📊
การแปลผล: พันธุ์ 2 และพันธุ์ 4 ให้ผลผลิตสูงสุดอยู่ในกลุ่มเดียวกัน (a) และสูงกว่าพันธุ์ 1 และพันธุ์ 3 (b) อย่างมีนัยสำคัญทางสถิติ
FORENSIC AUDIT · คดีสืบสวนข้อผิดพลาด

ตรวจสอบงานวิจัยของท่านด้วย Checklist วินิจฉัยนี้ก่อนลงมือปฏิบัติจริง:

CASE 01
ใช้ Fisher's LSD ทั้งที่ ANOVA ไม่ Sig (LSD Abuse): เมื่อ F-test ในตาราง ANOVA ไม่พบนัยสำคัญ (p > 0.05) แต่ผู้วิจัยกลับดึงดันทำ LSD ตรวจสอบทุกคู่จนเจอคู่ซิกเทียม
CASE 02
ใช้ Dunnett's Test เปรียบเทียบกันเองข้ามคู่: ใช้วิธี Dunnett ซึ่งออกแบบมาเพื่อเทียบกับ Control เท่านั้น ไปจับคู่ระหว่างทรีตเมนต์ทดลองกันเอง
CASE 03
ติดตัวอักษร a, b, c ขัดแย้งกับผลต่างค่าเฉลี่ยจริง: เขียนสรุปตัวอักษรบอกกลุ่มความต่างในตารางผลการทดลองผิดลำดับ หรือไม่รายงานค่าความคลาดเคลื่อนมาตรฐาน (SE)
🔍
หลักการเตือนใจ: ห้ามทดสอบพหุคูณเมื่อ ANOVA ไม่มีนัยสำคัญ ยกเว้นเป็นการทดสอบความเปรียบต่างที่วางแผนไว้ล่วงหน้า (Planned Contrasts)
