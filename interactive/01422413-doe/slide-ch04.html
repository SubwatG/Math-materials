บทที่ 4: แผนการทดลองแบบสุ่มในบล็อกสมบูรณ์ (RCBD)
MODULE 04 · RANDOMIZED COMPLETE BLOCK DESIGN

บทที่ 4: แผนการทดลองแบบสุ่มในบล็อกสมบูรณ์ (RCBD)

เมื่อพื้นที่หรือหน่วยทดลองไม่สม่ำเสมอเป็นเนื้อเดียวกัน การจัดบล็อก (Blocking) ขวางทิศทางความผันแปรจะช่วยดูดซับความแปรปรวนภายนอกออกจากความคลาดเคลื่อนได้อย่างมหาศาล

ตัวแบบy_{ij} = \mu + \tau_i + \beta_j + \varepsilon_{ij}
หลักการLocal Control (Blocking)
การแยก SSSS_{\text{Tr}} + SS_{\text{Block}} + SS_E
ทิศทางบล็อกPerpendicular to Gradient
1. หัวใจการจัดบล็อก
ภายในบล็อกเดียวกันต้องสม่ำเสมอที่สุด (Homogeneous within) แต่ระหว่างบล็อกยอมให้แตกต่างกันได้ (Heterogeneous between)
2. การลดทอน Error
ความแปรปรวนระหว่างบล็อกจะถูกดึงออกมาเป็น $SS_{\text{Block}}$ ทำให้ $SS_E$ และ $MS_E$ เล็กลง เพิ่มความไวของ $F$-test
3. สมมติฐาน Additivity
ตัวแบบสมมติว่าอิทธิพลของทรีตเมนต์และบล็อกเป็นแบบบวกสะสม ไม่มีปฏิสัมพันธ์ ($Treatment \times Block$) เกิดขึ้น
LINEAR MODEL · ตัวแบบคณิตศาสตร์

ตัวแบบเชิงเส้นและข้อกำหนดของ RCBD

ตัวแบบเชิงเส้นของ Randomized Complete Block Design:

สมการตัวแบบเชิงเส้น (Linear Model)
$$y_{ij} = \mu + \tau_i + \beta_j + \varepsilon_{ij}$$ โดย $i = 1, \dots, t$ และ $j = 1, \dots, b$
  • $y_{ij}$ = ค่าสังเกตของทรีตเมนต์ $i$ ในบล็อก $j$
  • $\mu$ = ค่าเฉลี่ยรวมแท้จริง
  • $\tau_i$ = อิทธิพลทรีตเมนต์ที่ $i$ โดย $\sum \tau_i = 0$
  • $\beta_j$ = อิทธิพลบล็อกที่ $j$ โดย $\sum \beta_j = 0$
  • $\varepsilon_{ij} \sim \text{NID}(0, \sigma^2)$ = ความคลาดเคลื่อนสุ่ม
ข้อกำหนด Additivity และการสุ่มในบล็อก
1. ไม่มี Interaction: สมมติว่าทรีตเมนต์แสดงผลในทิศทางเดียวกันในทุกบล็อก

2. Complete Block: ในแต่ละบล็อกต้องมีทรีตเมนต์ครบทุกตัว ($t$ ทรีตเมนต์)

3. การสุ่ม: สุ่มทรีตเมนต์ลงในแต่ละบล็อกแยกกันอย่างอิสระ
📌
ทิศทางการบล็อก: ต้องวางแนวบล็อกให้ 'ตั้งฉาก' กับแนวความลาดชันของดินหรือปัจจัยรบกวนเสมอ
SS DECOMPOSITION · การแยกผลรวมกำลังสอง

การแยกผลรวมกำลังสอง 3 ส่วนใน RCBD

ใน RCBD ความแปรปรวนรวม ($SS_{\text{Total}}$) ถูกแยกออกเป็น 3 ส่วนอิสระ:

สูตรการคำนวณ Sums of Squares
$$SS_{\text{Total}} = SS_{\text{Tr}} + SS_{\text{Block}} + SS_E$$
$$CF = \frac{Y_{\cdot\cdot}^2}{bt}, \quad SS_{\text{Total}} = \sum_{i=1}^t \sum_{j=1}^b y_{ij}^2 - CF$$
$$SS_{\text{Tr}} = \frac{\sum Y_{i\cdot}^2}{b} - CF, \quad SS_{\text{Block}} = \frac{\sum Y_{\cdot j}^2}{t} - CF$$
$$SS_E = SS_{\text{Total}} - SS_{\text{Tr}} - SS_{\text{Block}}$$
การกระจายองศาความเป็นอิสระ (df)
  • $df_{\text{Total}} = bt - 1$
  • $df_{\text{Tr}} = t - 1$
  • $df_{\text{Block}} = b - 1$
  • $df_E = (t - 1)(b - 1)$
  • สมบัติบวก: $df_{\text{Total}} = df_{\text{Tr}} + df_{\text{Block}} + df_E$
💡
ข้อแลกเปลี่ยน: เราเสีย $df$ ให้บล็อกไป $b-1$ องศาอิสระ แต่ได้การลดลงของ $SS_E$ คืนมา ซึ่งมักคุ้มค่าอย่างยิ่ง

HISTORICAL VIGNETTE · ประวัติศาสตร์สถิติโลก

เรื่องเล่าประวัติศาสตร์: Frank Yates & การจัดบล็อกขวางแนวระดับดิน (1930s)

"จงมองผืนดินให้ออก ความชื้นไหลไปทางไหน ธาตุอาหารลาดลงทางใด ให้สร้างกำแพงบล็อกขวางทางมันไว้!"

แฟรงก์ เยตส์ (Frank Yates) แห่งโรแธมสเตด ค้นพบว่าความลาดเอียงของเนินเขาทำให้แปลงทดลองด้านล่างได้รับน้ำและปุ๋ยสะสมมากกว่าด้านบน หากใช้ CRD ผลการทดลองจะลวงทันที เขาจึงวางหลักการจัดบล็อกให้ตั้งฉากกับแนวความลาดชัน (Contour Blocking) เพื่อดูดซับความผันแปรของดินออกมาเป็น SS_Block

บทเรียนสำคัญสู่ทฤษฎี
การจัดบล็อกที่ดีต้องมีเหตุผลทางกายภาพรองรับเสมอ ไม่ใช่การตีตารางสี่เหลี่ยมตามความชอบใจของผู้วิจัย
REAL CASE STUDY · การทดลองจริงภาคสนาม

กรณีศึกษาจริง: การทดลองพันธุ์อ้อยบนที่ลาดชัน ณ ไร่เกษตรกำแพงแสน

บริบทและการประยุกต์ใช้ในไทย
แปลงปลูกอ้อยที่มีความชื้นในดินไม่สม่ำเสมอเนื่องจากอยู่ใกล้คลองส่งน้ำฝั่งหนึ่ง การจัดแปลงทดลองเป็น 4 บล็อกขนานกับแนวคลอง (ขวางทิศทางการซึมของน้ำ) ทำให้ทรีตเมนต์พันธุ์อ้อยทุกพันธุ์ในแต่ละบล็อกเผชิญความชื้นระดับเดียวกัน ดึงความแปรปรวนของน้ำออกจาก Error ได้อย่างสมบูรณ์
คำแนะนำสำหรับวิทยานิพนธ์

ตรวจสอบทิศทางแดด ลม และการระบายน้ำก่อนเคาะผังแปลง หากพบว่ามีความลาดชัน 2 ทิศทางพร้อมกัน RCBD จะเอาไม่อยู่ ต้องอัปเกรดเป็น Latin Square

WORKED EXAMPLE · ตัวอย่างการคำนวณจริง

ตัวอย่างการคำนวณ RCBD และการกู้ข้อมูลสูญหาย

สมมติการทดสอบพันธุ์อ้อย 4 พันธุ์ ($t=4$) ใน 4 บล็อก ($b=4, N=16$) มีข้อมูลดังนี้:

1. การคำนวณตาราง ANOVA ของ RCBD
  • $CF = 40,000.0, \quad SS_{\text{Total}} = 380.0$
  • $SS_{\text{Tr}} = 240.0, \quad SS_{\text{Block}} = 95.0$
  • $SS_E = 380.0 - 240.0 - 95.0 = 45.0$
  • $MS_{\text{Tr}} = 240.0 / 3 = 80.0, \quad MS_E = 45.0 / 9 = 5.00$
  • $F_{\text{calc}} = 80.0 / 5.00 = 16.00 > F_{0.05, 3, 9} = 3.86$ (Sig!)
  • $RE = \frac{3(31.67) + 4(3)(5.00)}{15(5.00)} = \frac{155.0}{75.0} = 206.7\%$
2. สูตรประมาณค่าข้อมูลสูญหาย (Missing Plot)
หากข้อมูลแปลงทรีตเมนต์ $i$ ในบล็อก $j$ สูญหาย 1 ค่า สามารถประมาณได้ด้วยสูตร:
$$\hat{y}_{ij} = \frac{t Y'_{i\cdot} + b Y'_{\cdot j} - Y'_{\cdot\cdot}}{(t-1)(b-1)}$$
  • $Y'_{i\cdot}$ = ผลรวมทรีตเมนต์ $i$ ที่เหลืออยู่
  • $Y'_{\cdot j}$ = ผลรวมบล็อก $j$ ที่เหลืออยู่
  • $Y'_{\cdot\cdot}$ = ผลรวมข้อมูลทั้งหมดที่เหลืออยู่
  • ข้อบังคับ: ต้องลด $df_E$ และ $df_{\text{Total}}$ ลง 1 เสมอ
📊
สรุป: การจัดบล็อกช่วยเพิ่มประสิทธิภาพการทดลองขึ้นถึง 106.7% เมื่อเทียบกับ CRD บนผืนดินเดียวกัน
