MODULE 08 · FACTORIAL EXPERIMENTS (2^K, 3^K)

บทที่ 8: แผนการทดลองแบบแฟกทอเรียล (Factorial)

ศึกษาอิทธิพลของปัจจัยตั้งแต่สองปัจจัยขึ้นไปพร้อมกันในทุกระดับ เพื่อค้นพบอิทธิพลร่วม (Interaction Effect) และปรากฏการณ์เสริมฤทธิ์ที่การทดลองทีละปัจจัยไม่สามารถตรวจจับได้

ตัวแบบy_{ijk} = \mu + A_i + B_j + (AB)_{ij} + \varepsilon_{ijk}
จุดแข็งตรวจจับ Interaction Effect
ข้อห้ามห้ามสรุป Main Effect เดี่ยวๆ เมื่อมี Interaction
ประสิทธิภาพเหนือกว่า One-Factor-At-A-Time (OFAT)
1. อิทธิพลร่วม (Interaction)
เกิดขึ้นเมื่อผลของปัจจัยหนึ่งขึ้นอยู่กับระดับของอีกปัจจัยหนึ่ง เช่น ปุ๋ยจะให้ผลดีก็ต่อเมื่อมีน้ำเพียงพอเท่านั้น
2. การประหยัดตัวอย่าง
ทุกหน่วยทดลองถูกนำมาใช้ประเมินทั้งอิทธิพลหลัก A, อิทธิพลหลัก B และอิทธิพลร่วม AB ได้พร้อมกันในตัวแบบเดียว
3. แผนแบบ 2^k
โครงสร้าง $k$ ปัจจัย ปัจจัยละ 2 ระดับ (+/-) เป็นรากฐานสำคัญของการคัดกรองปัจจัย (Screening Design) ในอุตสาหกรรม
FACTORIAL MODEL · ตัวแบบแฟกทอเรียล

ตัวแบบเชิงเส้นของการทดลองแบบแฟกทอเรียล

ตัวแบบเชิงเส้นของการทดลอง 2 ปัจจัย ($a \times b$ Factorial Experiment):

สมการตัวแบบเชิงเส้น (Linear Model)
$$y_{ijk} = \mu + A_i + B_j + (AB)_{ij} + \varepsilon_{ijk}$$ โดย $i=1..a, j=1..b, k=1..n$
  • $y_{ijk}$ = ค่าสังเกตที่ระดับ $A_i$ ร่วมกับ $B_j$ ซ้ำที่ $k$
  • $\mu$ = ค่าเฉลี่ยรวมแท้จริง
  • $A_i$ = อิทธิพลหลักของปัจจัย A โดย $\sum A_i = 0$
  • $B_j$ = อิทธิพลหลักของปัจจัย B โดย $\sum B_j = 0$
  • $(AB)_{ij}$ = อิทธิพลร่วม (Interaction) โดย $\sum_i (AB)_{ij} = \sum_j (AB)_{ij} = 0$
  • $\varepsilon_{ijk} \sim \text{NID}(0, \sigma^2)$ = ความคลาดเคลื่อนสุ่ม
ความหมายของ Interaction (อิทธิพลร่วม)
ไม่มี Interaction: ผลต่างระหว่างระดับของ A มีค่าเท่ากันในทุกระดับของ B เส้นกราฟตอบสนองจะ 'ขนานกัน'

มี Interaction: ผลต่างของ A เปลี่ยนไปตามระดับของ B เส้นกราฟตอบสนองจะ 'ไม่ขนานกัน' หรือ 'ตัดกัน'
📌
กฎเหล็ก: หากเกิด Interaction อย่างมีนัยสำคัญ ห้ามสรุป Main Effect แยกเดี่ยวๆ เพราะจะเป็นการชี้นำที่ผิดพลาด
SS DECOMPOSITION · การแยกผลรวมกำลังสอง

การแยกผลรวมกำลังสองในแผนแบบ Factorial

ใน Factorial สองปัจจัย ความแปรปรวนรวมถูกแยกออกเป็น 4 ส่วนอิสระ:

สูตรการคำนวณ Sums of Squares
$$SS_{\text{Total}} = SS_A + SS_B + SS_{AB} + SS_E$$
$$CF = \frac{Y_{\cdot\cdot\cdot}^2}{abn}, \quad SS_A = \frac{\sum Y_{i\cdot\cdot}^2}{bn} - CF, \quad SS_B = \frac{\sum Y_{\cdot j\cdot}^2}{an} - CF$$
$$SS_{\text{Subtotal}(AB)} = \frac{\sum \sum Y_{ij\cdot}^2}{n} - CF$$
$$SS_{AB} = SS_{\text{Subtotal}(AB)} - SS_A - SS_B, \quad SS_E = SS_{\text{Total}} - SS_{\text{Subtotal}(AB)}$$
การกระจายองศาความเป็นอิสระ (df)
  • $df_{\text{Total}} = abn - 1$
  • $df_A = a - 1$
  • $df_B = b - 1$
  • $df_{AB} = (a - 1)(b - 1)$
  • $df_E = ab(n - 1)$
  • สมบัติบวก: $abn-1 = (a-1) + (b-1) + (a-1)(b-1) + ab(n-1)$
💡
ประสิทธิภาพ: การใช้ Factorial ได้ข้อมูลเท่ากับการทดลองเดี่ยว 2 ครั้ง แต่ใช้จำนวนหน่วยทดลองน้อยกว่าครึ่งหนึ่ง

HISTORICAL VIGNETTE · ประวัติศาสตร์สถิติโลก

เรื่องเล่าประวัติศาสตร์: Frank Yates (1937) & การสิ้นสูญของวิธีทดลองทีละปัจจัย (OFAT)

"ธรรมชาติไม่ได้ทำงานทีละปัจจัย ปุ๋ยจะไร้ค่าหากไม่มีน้ำ และน้ำจะไร้ผลหากขาดปุ๋ย!"

ในอดีตนักวิทยาศาสตร์เชื่อว่าต้องทดลองแบบ 'แปรผันทีละปัจจัยเดียว' (OFAT) แต่แฟรงก์ เยตส์ ตีพิมพ์รายงานประวัติศาสตร์ในปี 1937 พิสูจน์ว่า OFAT ล้มเหลวโดยสิ้นเชิงในการตรวจจับอิทธิพลร่วม (Interaction) แผนแบบ Factorial ช่วยประหยัดตัวอย่างและค้นพบปรากฏการณ์เสริมฤทธิ์ (Synergism) ของธรรมชาติ

บทเรียนสำคัญสู่ทฤษฎี
OFAT ให้ภาพลวงตาของความง่าย แต่ซ่อนความอันตรายในการสรุปผลลัพธ์ที่ผิดพลาดเมื่อธรรมชาติมีพฤติกรรมไม่เป็นเส้นตรง
REAL CASE STUDY · การทดลองจริงภาคสนาม

กรณีศึกษาจริง: การทดลองปุ๋ยไนโตรเจน x ระดับการให้น้ำในแปลงข้าวโพด

บริบทและการประยุกต์ใช้ในไทย
แปลงทดลองศึกษาปุ๋ยไนโตรเจน 3 ระดับ ร่วมกับการให้น้ำ 2 ระดับ เมื่อพลอตกราฟพบว่า เมื่อไม่ให้น้ำ การเพิ่มปุ๋ยกลับทำให้ข้าวโพดเหี่ยวเฉา (ผลลบ) แต่เมื่อให้น้ำเพียงพอ การเพิ่มปุ๋ยกลับให้ผลผลิตพุ่งสูงขึ้นอย่างก้าวกระโดด นี่คือตัวอย่างคลาสสิกของ Interaction ที่ห้ามสรุปผลปุ๋ยเดี่ยวๆ
คำแนะนำสำหรับวิทยานิพนธ์

เมื่อนำเสนองานวิจัย Factorial ต้องมีกราฟ Interaction Plot ประกอบตาราง ANOVA เสมอ เพื่อให้คณะกรรมการเห็นภาพปฏิสัมพันธ์ที่ชัดเจน

WORKED EXAMPLE · ตัวอย่างการคำนวณจริง

ตัวอย่างการคำนวณการทดลอง 2² Factorial

การทดลองศึกษาปุ๋ย N (2 ระดับ: $N_0, N_1$) ร่วมกับปุ๋ย P (2 ระดับ: $P_0, P_1$) ทำซ้ำ $n=3$ ซ้ำ ($N=12$):

1. ผลรวมทรีตเมนต์และ Contrast ของเยตส์
  • ทรีตเมนต์ 4 แบบ: $(1)=60, n=90, p=75, np=135$
  • Contrast ปัจจัย N: $[N] = np + n - p - (1) = 135 + 90 - 75 - 60 = 90.0$
  • Contrast ปัจจัย P: $[P] = np + p - n - (1) = 135 + 75 - 90 - 60 = 60.0$
  • Contrast อิทธิพลร่วม: $[NP] = np + (1) - n - p = 135 + 60 - 90 - 75 = 30.0$
2. การคำนวณ SS และตาราง ANOVA
  • สูตรผลรวมกำลังสอง: $SS = \frac{[\text{Contrast}]^2}{4n} = \frac{[\text{Contrast}]^2}{12}$
  • $SS_N = 90^2 / 12 = 675.0 \quad (df=1)$
  • $SS_P = 60^2 / 12 = 300.0 \quad (df=1)$
  • $SS_{NP} = 30^2 / 12 = 75.0 \quad (df=1)$
  • สมมติ $SS_E = 96.0 \quad (df = 4(3-1) = 8) \implies MS_E = 12.0$
  • $F_N = 56.25, F_P = 25.00, F_{NP} = 6.25 > F_{0.05, 1, 8} = 5.32$ (Sig ทุกตัว!)
📊
สรุป: เกิด Interaction ระหว่าง N และ P อย่างมีนัยสำคัญ ปุ๋ย N จะให้ผลดีสูงสุดเมื่อใส่ร่วมกับปุ๋ย P เท่านั้น
FORENSIC AUDIT · คดีสืบสวนข้อผิดพลาด

แฟ้มคดีอาชญากรรมทางสถิติ: 3 กับดักยอดฮิต

ตรวจสอบงานวิจัยของท่านด้วย Checklist วินิจฉัยนี้ก่อนลงมือปฏิบัติจริง:

CASE 01
สรุป Main Effect ทั้งที่มี Interaction รุนแรง: รายงานว่า 'ปุ๋ยไนโตรเจนเพิ่มผลผลิตเฉลี่ยอย่างมีนัยสำคัญ' ทั้งที่เส้นกราฟตัดกันรุนแรง (ปุ๋ยให้ผลดีเฉพาะในกลุ่มที่ให้น้ำเท่านั้น) เป็นการชี้นำที่ผิด
CASE 02
ไม่ทดสอบ Simple Effects เมื่อ Interaction Sig: เมื่อพจน์ A x B มีนัยสำคัญ ผู้วิจัยกลับไม่วิเคราะห์แยกย่อยทีละระดับของอีกปัจจัยหนึ่ง (Simple Effect Analysis) ทำให้เสียโอกาสค้นพบข้อสรุปเชิงลึก
CASE 03
สับสนลำดับการคูณเครื่องหมายใน Yates' Algorithm: คำนวณผลรวมความเปรียบต่างในตาราง 2³ Factorial ด้วยวิธีของเยตส์แต่สับสนเครื่องหมายบวก-ลบ
🔍
หลักการเตือนใจ: เมื่อ Interaction มีนัยสำคัญ การทดสอบเปรียบเทียบพหุคูณต้องทำในระดับ Simple Effects ห้ามทำบนค่าเฉลี่ย Marginal Means
