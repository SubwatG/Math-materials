สไลด์ 6/10 เจาะ Riemann พร้อมเลข

สูตรเดียว จุดสามแบบ เลขจำ 1 5 2.5

dx = (b-a)/n ซ้ายใช้ a+i dx ขวาใช้ a+(i+1) dx กลางใช้ a+(i+0.5) dx
กรณี x² บน [0,2] n=2จุดผล
left0, 11
right1, 25
midpoint0.5, 1.52.5
ค่าจริงอินทิกรัล8/3 ประมาณ 2.6667
ทฤษฎีที่ต้องพูดคือ f ต่อเนื่องบน [a,b] เมื่อ n โตค่าประมาณลู่เข้าอินทิกรัล ถ้า f เพิ่มแล้ว L น้อยกว่า A น้อยกว่า R midpoint มักตรงสุด
เทียบกระเบื้องปูที่นา ยิ่ง n มากยิ่งตรง อย่าลืมคูณ dx ทุกแท่ง กราฟใต้แกนต้องใช้ค่าสัมบูรณ์

สไลด์ 7/10 กราฟกับ LaTeX กันพังอย่างไร

plotter วาดแท่ง math_render กัน KaTeX แตก

plotter: ใช้ matplotlib Agg คืน fig ax แปลงนิพจน์ด้วย lambdify วาดเส้นสี #105D38 แท่งสี #3D7A56 แรเงาสี #B9D4C4 label อังกฤษทั้งหมด ใช้ Rectangle กับ fill_between

math_render: st.latex ต้องเป็น pure LaTeX ไม่มี $ ไม่มีไทย ถ้ามีให้ fallback เป็น markdown มี has_thai strip_math_delimiters render_latex render_steps ขั้นที่ 1 2 3
widget label ไม่รองรับ KaTeX ให้ใช้ Unicode แทน
ถ้ากรรมการถามว่าทำไม label อังกฤษ ตอบว่า matplotlib กับ KaTeX ใน widget เสถียรกว่า
