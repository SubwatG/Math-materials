ฟังก์ชัน $\arctan(t)$ รับอินพุตเป็นอัตราส่วนค่าเดียว $t = \frac{y}{x}$ ทำให้มันไม่รู้ว่าเศษและส่วนเป็นบวกหรือลบมาตั้งแต่แรก:

• จุดใน Q1: $z_1 = 1+i \implies \frac{y}{x} = \frac{1}{1} = 1$ $\arctan(1) = 45^\circ$ ✅
• จุดใน Q3: $z_2 = -1-i \implies \frac{y}{x} = \frac{-1}{-1} = 1$ $\arctan(1) = 45^\circ$ ❌

จะเห็นว่า $\frac{-1}{-1}$ กลายเป็น $+1$ ไปแล้ว ทำให้ฟังก์ชัน $\arctan$ "ตาบอด" มองเห็นจุด $z_2$ อยู่ในจัตุภาคที่ 1 ทั้งที่ในความเป็นจริงเวกเตอร์ชี้ไปทางทิศตรงกันข้าม ($180^\circ$ ห่างกัน)!

3 เหตุผลสำคัญ: ทำไมจึงนิยมเลือกค่าหลักของอาร์กิวเมนต์ในช่วง $(-\pi, \pi]$ ?

ในบทนี้กำหนด principal argument โดยเลือก $\mathrm{Arg}(z) \in (-\pi, \pi]$ ซึ่งเป็นหนึ่งใน convention มาตรฐานที่ใช้แพร่หลายและมีสมบัติทางเรขาคณิตที่งดงาม

1 สมมาตรกับการสังยุค (Conjugate Symmetry)

บนระนาบเชิงซ้อน การสังยุค $\bar{z} = x-yi$ คือการสะท้อนข้ามแกนจริง ($x$-axis) หากใช้ช่วง $(-\pi, \pi]$ มุมจะสะท้อนเครื่องหมายอย่างสมบูรณ์แบบ:

$$\mathrm{Arg}(\bar{z}) = -\mathrm{Arg}(z) \quad (\text{เมื่อ } z \notin (-\infty, 0])$$

*หากใช้ช่วง $[0, 2\pi)$ มุมสังยุคของ $45^\circ$ จะกลายเป็น $315^\circ$ ซึ่งทำลายสมบัติความเป็นฟังก์ชันคี่ (Odd Function)

2 ความต่อเนื่องของฟังก์ชัน $\mathrm{Log}(z)$

การเลือก branch นี้ทำให้ principal logarithm เป็นฟังก์ชันเชิงเดี่ยวและ holomorphic บน $\mathbb{C} \setminus (-\infty, 0]$ โดยแกนจริงลบรวมทั้ง 0 เป็น branch cut:

$$\lim_{y \to 0^+} \mathrm{Arg}(x+yi) = \pi, \quad \lim_{y \to 0^-} \mathrm{Arg}(x+yi) = -\pi \quad (x < 0)$$

ให้รอยตัดกิ่งวางตัวอยู่บนแกนจริงลบอย่างเป็นธรรมชาติและสอดคล้องกับการวิเคราะห์เชิงซ้อนขั้นสูง

3 ฟังก์ชัน atan2 ในระบบคอมพิวเตอร์

ฟังก์ชัน `atan2(y, x)` ใช้เครื่องหมายของทั้ง $y$ และ $x$ เพื่อเลือกจัตุภาคได้ถูกต้อง โดยระบบคอมพิวเตอร์ทั่วไปให้มุมในช่วงใกล้เคียง $[-\pi, \pi]$:

import math
theta = math.atan2(-1, -1) # -> -2.356 rad (-135°)

หากต้องการ convention ของบทนี้ $(-\pi, \pi]$ ให้ normalize ค่า $-\pi$ เป็น $+\pi$ เพื่อความสอดคล้องสมบูรณ์

ตารางสูตรการหา $\mathrm{Arg}(z)$ สำหรับทุกกรณีเมื่อ $z \neq 0$

ตำแหน่งของจุด $z = x+yi$ เครื่องหมายพิกัด ช่วงมุมจริงใน $(-\pi, \pi]$ สูตรคำนวณ $\mathrm{Arg}(z)$ ตัวอย่าง ($z$)
จัตุภาคที่ 1 (Quadrant I) $x > 0, y > 0$ $\left(0, \frac{\pi}{2}\right)$ $\theta = \arctan(y/x)$ $1+i \implies \frac{\pi}{4}$ ($45^\circ$)
จัตุภาคที่ 4 (Quadrant IV) $x > 0, y < 0$ $\left(-\frac{\pi}{2}, 0\right)$ $\theta = \arctan(y/x)$ $1-i \implies -\frac{\pi}{4}$ ($-45^\circ$)
จัตุภาคที่ 2 (Quadrant II) ⚠️ $x < 0, y > 0$ $\left(\frac{\pi}{2}, \pi\right)$ $\theta = \arctan(y/x) \mathbf{+ \pi}$ $-1+\sqrt{3}i \implies \frac{2\pi}{3}$ ($120^\circ$)
จัตุภาคที่ 3 (Quadrant III) ⚠️ $x < 0, y < 0$ $\left(-\pi, -\frac{\pi}{2}\right)$ $\theta = \arctan(y/x) \mathbf{- \pi}$ $-1-i \implies -\frac{3\pi}{4}$ ($-135^\circ$)
แกนจริง (Real Axis) $x \neq 0, y = 0$ $\{0, \pi\}$ $\theta = 0 \text{ (เมื่อ } x>0), \; \pi \text{ (เมื่อ } x<0)$ $2 \implies 0, \; -2 \implies \pi$ ($180^\circ$)
แกนจินตภาพ (+Im / -Im) $x = 0, y \neq 0$ $\{\frac{\pi}{2}, -\frac{\pi}{2}\}$ $\theta = \frac{\pi}{2} \text{ (เมื่อ } y>0), \; -\frac{\pi}{2} \text{ (เมื่อ } y<0)$ $3i \implies \frac{\pi}{2}, \; -2i \implies -\frac{\pi}{2}$
