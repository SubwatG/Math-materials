ตัวสถิติทดสอบ: Z หรือ t?

ฝึกเลือกตัวสถิติทดสอบให้ถูกต้องก่อนคำนวณ: ดูเงื่อนไข σ ทราบหรือไม่ ขนาดตัวอย่าง และการแจกแจงประชากร

Case 1: ทราบ σ²

Z-test โดยใช้ σ

$$Z = \frac{\bar{x} - \mu_0}{\sigma / \sqrt{n}}$$

ทราบความแปรปรวนประชากร: ใช้ Z เสมอ ไม่สนใจขนาด n

Case 2: ไม่ทราบ σ², n < 30

t-test โดยใช้ s

$$t = \frac{\bar{x} - \mu_0}{s / \sqrt{n}}$$

ต้องประชากรแจกแจงปกติ ($df = n-1$)

Case 3: ไม่ทราบ σ², n ≥ 30

Z-test โดยใช้ s (CLT)

$$Z = \frac{\bar{x} - \mu_0}{s / \sqrt{n}}$$

CLT: ประชากรไม่ปกติก็ใช้ได้
