### ม.3 — สถิติ

### ม.3 — วงกลม (เรขาคณิต)

- [ห้องทดลองเรขาคณิตวงกลม (Circle Theorems Interactive Lab)](interactive/m3-circles/index.html) — ลากจุดเพื่อสำรวจคุณสมบัติและทฤษฎีบทวงกลมทุกข้อตามหลักสูตร สสวท. ม.3 เล่ม 2 (มุมที่จุด ศก., มุมในส่วนโค้ง, มุมในครึ่งวงกลม, สี่เหลี่ยมแนบในวงกลม, การตั้งฉากแบ่งครึ่งคอร์ด, เส้นสัมผัส และทฤษฎีบทส่วนโค้งสลับ) พร้อมมโนทัศน์สามเหลี่ยมหน้าจั่วและตัวอย่างโจทย์

### ม.3 — วิทยาศาสตร์ (หน่วยที่ 5: ปฏิกิริยาเคมีและวัสดุในชีวิตประจำวัน)

- [แบบทดสอบและแล็บจำลอง: ปฏิกิริยาเคมี & วัสดุในชีวิตประจำวัน (ตอนที่ 2)](interactive/middle-science-reactions-and-materials/index.html) — แบบทดสอบวัดความเข้าใจ 6 ตอน (26 ข้อ) ครอบคลุมปฏิกิริยากรดกับสารประกอบคาร์บอเนต การทดสอบแก๊ส สนิมเหล็กและการป้องกัน การเผาไหม้และสิ่งแวดล้อม แล็บทดสอบพอลิเมอร์ต่อความร้อน เซรามิกส์ โลหะผสม และวัสดุผสม (Composites) 3R

## GitHub Pages

Repository นี้เตรียมไว้สำหรับเปิด GitHub Pages จาก branch `main` และ folder `/` (root)

หลังสร้าง repository และ push แล้ว เปิดใช้งานได้ด้วย:

```bash
gh api --method POST /repos/<owner>/Math-materials/pages -f source.branch=main -f source.path=/
```

หรือใน GitHub UI:

Settings → Pages → Build and deployment → Deploy from a branch → `main` / `/ (root)`
